# 사전 규칙 (실행 전 동결, 실행 중 변경 금지)

## 공통
- 튜닝(1·2단계): data_seed=4321, run 100,101,102, 10라운드, 조기종료 없음. 확정(3단계): data_seed=1234, run 0~9, 20라운드, 조기종료 없음(사후 시뮬레이션).
- 궤적(1·2단계)은 항상 원본 MSEAvg(`GlobalAggregator.fed_mse_avg`)를 따른다. 로깅/평가는 학습 궤적을 바꾸지 않는다(스크래치 모델 사용).
- 가중식: w_i ∝ n_i^β · exp(−z_i/T), z_i=(s_i−median(s))/(std(s)+1e-8), 참가 모델 안에서 표준화, 점수 s는 "낮을수록 좋다"로 통일.
- B 점수: l_{i,g}=clip(log(m_{i,g}/r_g),−2,2), r_g=참가 모델 블록 g MSE의 중앙값, s_i=mean_g l + λ·max_g l. (블록 g = dev의 클라이언트 블록 10개)
- A1=dev 위 모델 shrink loss, A2=dev 잠재(dev 통계로 표준화) 중심거리 p95/p50, A3=dev 잠재 평균노름/참가 모델 중앙값. 모두 "낮을수록 좋다" 가설 방향 고정.
- 조기종료 사후 시뮬레이션은 원본 코드를 글자 그대로 복제(개선 라운드도 worse=0 후 +1 되는 동작 포함, worse>1이면 중단).

## 1단계 판정
- B(a): 라운드별 (블록별 중앙값 MSE의 max/min) 의 라운드 중앙값 ≥ 3 (거짓이면 B 탈락).
- B(b): MSEAvg 풀링 MSE 순위 vs 블록 로그비 평균(λ=0) 순위의 Spearman < 0.8 인 라운드 비율 ≥ 0.5.
- B(c): 약한 클라이언트 = 진단 궤적 평균 AUC가 가장 낮은 2개. 라운드의 ≥50%에서 참가 모델 중 약한 블록 로그비(무클립) 최대값 > log(1.25).
- B 가능 = (a)&(b)&(c).
- A 점수별: (a) 라운드별 모델 간 점수 sd > 모델별 dev 부트스트랩(20회, 행 재표집) sd 평균, 이 조건 라운드 비율 ≥ 0.6; (b) Spearman(−s_i, 로컬모델 10클라이언트 평균 AUC) > 0.3 인 라운드 비율 ≥ 0.6. A 가능 = 하나 이상의 점수가 (a)&(b). 통과한 점수만 2단계로.
- 부수: 가중 엔트로피/ln(5) > 0.98 이면 MSEAvg≈균등.
- 둘 다 탈락이면 멈추고 보고.

## 2단계 판정
- 후보: 균등, FedAvg, MSEAvg(재구현), B 격자(β∈{0,0.5}, T∈{0.5,1,2}, λ∈{0,0.5}), 통과한 A 점수별 격자(β∈{0,0.5}, T∈{0.5,1,2}), Dirichlet(1) 무작위 10개.
- 지표(라운드 4~10, run 100~102 전체 평균): Δ평균AUC, Δ최저클라이언트AUC (후보−MSEAvg, %p).
- 천장: (run,라운드)마다 [무작위 10개 중 평균AUC 최대 − 균등 평균AUC] 의 평균(4~10라운드). < 0.3%p 이면 A·B 모두 탈락 → 멈추고 보고. (최저 AUC 천장은 참고만.)
- 선택: 가족(A, B)별로 eligible = (Δ평균 ≥ −0.2 and Δ최저 ≥ −0.2), 점수 = max(Δ평균/0.3, Δ최저/1.0) 최대인 1개 → A*, B*. eligible 없으면 그 가족 탈락. 둘 다 탈락이면 멈춤. 선택은 `analysis/frozen_selection.json` 으로 동결, sha256 기록, 이후 변경 금지.

## 3단계 판정
- 방법: FedAvg, MSEAvg, B*, A*. 주 지표(run별): 라운드 4~10 평균의 (a) 10클라이언트 평균 AUC, (b) 최저 클라이언트 AUC.
- MSEAvg 대비 run별 짝지은 차이(%p): 평균, 95% 부트스트랩 CI(run 재표집 10000회, percentile), 짝지은 t검정, Wilcoxon. 검정 4개(A,B×2지표) t검정 p를 Holm 보정.
- "유의미한 개선" = 어느 한 주 지표에서 (CI 하한 > 0) & (Holm 보정 t p < 0.05) & (평균 효과 ≥ 실질기준: 평균AUC +0.3%p 또는 최저 +1.0%p) 이고, 다른 주 지표의 평균 차이 ≥ −0.2%p. (엄격 비열등=그 지표 CI 하한 > −0.2 도 참고로 병기.)
- 아니면 "개선 없음"을 CI와 함께 보고.
