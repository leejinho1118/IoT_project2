# 사전 규칙 2 (H1·H2 후속 검증; 실행 전 동결, 실행 중 변경 금지)

## 0. 공통 정의
- 셀 6개: 학습방식 {직렬 S, 병렬 P} × 집계 {균등 U, FedAvg A, MSEAvg M}. 직렬 S-A/S-M은 원본 `fed_avg`/`fed_mse_avg` 호출, U는 `make_weights(n,0,None)`+`mix_states`. 병렬은 라운드 시작 global에서 각 클라이언트가 독립 학습.
- 주 분할: data_seed=1234, run 0~9. 확인 분할: data_seed=4321, run 100~104. 20라운드 전부, 조기종료 없음. 하이퍼파라미터는 논문값(hybrid, non-IID 10, epoch 100, lr 1e-5).
- 비교 허용오차 TOL = 1e-9: 모든 "≥/>/≤/<" 임계값 비교는 TOL을 유리하지 않은 방향이 아니라 중립으로 적용한다. 구체적으로 `x ≥ c`는 `x ≥ c − TOL`, `x > c`는 `x > c + TOL`, `x ≤ c`는 `x ≤ c + TOL`, `x < c`는 `x < c − TOL`로 계산한다. 단위는 %p(AUC×100).
- 지표(run별): 라운드 4~10(양끝 포함 7개) 평균. M1 = 라운드별 10클라이언트 평균 AUC의 평균. M2 = 라운드별 10클라이언트 중 최저 AUC의 평균. 민감도(판정 불사용): 라운드 11~20 평균, 논문 프로토콜(사후 조기종료 마지막 라운드의 M1/M2), 라운드별 클라이언트 간 표준편차.
- 조기종료 사후 시뮬레이션: 원본 코드 글자 그대로(`unit_checks.py::sim_stop`, patience=1, global_loss 기준).
- 통계: 짝지은 run 차이(%p) = 처리 − 기준. 95%/90% CI = run 재표집 부트스트랩 percentile 10000회, `numpy.random.RandomState(20261109)` 고정(각 CI 계산마다 새로 시드). 짝지은 t(양측), Wilcoxon signed-rank(양측, 동률·0차이는 scipy 기본 zero_method='wilcox'). 부트스트랩 CI와 t p는 판정에 쓰고 Wilcoxon은 참고.

## 1. 안전/발산 기준 (멈춤 조건)
- 병렬 셀(P-*)의 어떤 run이든 라운드 ≥5에서 10클라이언트 평균 AUC < 0.90이면 "발산" → 멈추고 보고.
- 단위 검증 FAIL, 직렬 셀이 기존 결과와 불일치, sol "문제 있음", 예상 시간 1.5배 초과, 디스크/GPU 오류, 이 규칙으로 판정 불가한 경계도 멈춤.

## 2. H1 판정 (S-M − S-U, 주 분할 run 0~9)
- 지표 m ∈ {M1, M2}, 동등 한계 δ(M1)=0.3%p, δ(M2)=1.0%p.
- 동등(m): 90% CI가 (−δ, +δ) 안(양끝 포함: 하한 ≥ −δ, 상한 ≤ +δ).
- 차이 있음(m): 95% CI가 0을 제외(하한 > 0 또는 상한 < 0)하고 |평균| ≥ δ.
- 그 외(m) = 판정불가(검정력 부족).
- 종합: 두 지표 모두 "동등" → H1 = **동등**. 한 지표라도 "차이 있음" → H1 = **차이 있음**. 그 밖 → **판정불가**.
- 기전 점검(참고, 종합 판정 불변): (a) S-M 전 run·전 라운드(200개) 중 MSEAvg 가중 엔트로피/ln(참가수) > 0.98인 비율 ≥ 95%; (b) S-M에서 같은 로컬 모델의 균등혼합 AUC − MSEAvg 혼합 AUC(10클라이언트 평균, 절댓값 평균, 전 라운드) < 0.1%p.
- 보조(참고): S-A − S-M 차이를 라운드 4~10 고정으로 보고(논문의 96.28 vs 96.84가 조기종료 길이 때문인지), 논문 프로토콜 값도 병기.

## 3. H2 판정 (병렬 − 직렬, 주 분할 run 0~9)
- 대비 3개: P-U−S-U, P-A−S-A, P-M−S-M. 지표 2개(M1, M2) → 6검정. 짝지은 t p를 Holm 보정(6개 가족).
- 임계: M1 +0.3%p, M2 +1.0%p. 악화 임계는 대칭(−0.3, −1.0), 다른 지표 허용 하한은 ∓0.2%p 이내.
- 개선(대비 c): 어느 한 지표 m에서 (95% CI 하한 > 0) & (Holm t p < 0.05) & (평균 ≥ 그 지표 임계) 이고, 다른 지표 평균 ≥ −0.2.
- 악화(대비 c): 어느 한 지표 m에서 (95% CI 상한 < 0) & (Holm t p < 0.05) & (평균 ≤ −그 지표 임계) 이고, 다른 지표 평균 ≤ +0.2.
- 개선과 악화가 모두 성립하면 "판정불가". 둘 다 아니면 "차이 없음/판정불가".
- 주 대비(요약 판정): P-A − S-M (병렬 FedAvg vs 논문 방식 MSEAvg), 같은 규칙·같은 Holm 가족(추가 검정 2개이므로 이 대비는 Holm 가족 6개와 별도로 raw p와 Holm p를 병기).
- 약한 클라이언트(S-M 주 분할 run 0~9, 라운드 4~10 평균 AUC가 가장 낮은 2개)의 클라이언트별 Δ는 기술통계로만 보고(판정 불사용).
- H2a(참고): 기존 1단계 로그(`Checkpoint/Results/EXP/S1`)에서 직렬 학습순서와 로컬 모델 AUC의 라운드별 Spearman의 평균과 ρ>0.3 비율.

## 4. 확인 분할 (data_seed=4321, run 100~104, 같은 6셀)
- 주 분할 판정 후에만 실행, 설정 변경 금지. 같은 분석으로 H1/H2 판정을 다시 낸다(n=5이므로 판정불가가 많을 수 있음).
- 재현 = 주 분할과 같은 종합 판정(H1) / 같은 대비별 판정(H2). 아니면 "재현 실패"로 보고하되 결론은 주 분할 기준.

## 5. 결론 권고 규칙
- H1=동등 이고 H2 모든 대비가 개선 아님 → 재검증형(MSEAvg 무의미) 권고.
- H2에서 P-A−S-M 또는 병렬 대비가 개선 → 구조형(병렬 학습) 권고.
- 둘 다 아니면 "개선 없음"을 CI와 함께 보고.
