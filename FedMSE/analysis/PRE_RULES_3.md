# 사전 규칙 3 (직렬>병렬 격차의 원인 규명; 실행 전 동결, 실행 중 변경 금지)

## 0. 공통 정의 (PRE_RULES_2와 동일한 것은 그대로)
- 집계는 **균등평균(U)** 으로 통일. 주 분할 data_seed=1234, run 0~9. 확인 분할(data_seed=4321, run 100~)은 이번에 쓰지 않으며 시드를 섞지 않는다.
- 20라운드 전부, 조기종료 없음, 하이퍼파라미터는 논문값(hybrid, epoch 100, lr 1e-5, batch 12, 로컬 early stop patience 3).
- 지표/단위/TOL/부트스트랩/짝지은 t는 PRE_RULES_2 §0과 같다: M1(라운드 4~10, 10클라 평균 AUC의 평균), M2(같은 구간 최저 AUC의 평균), %p 단위, TOL=1e-9(중립 적용), 부트스트랩 10000회 `RandomState(20261109)`(CI마다 새로 시드), 95%/90% percentile CI.
- 동등 한계 δ(M1)=0.3%p, δ(M2)=1.0%p. (사용자 확정 결정 1)
- 격차 G_m(cell) = mean over runs of [S-U − cell] (m ∈ {M1, M2}, 라운드 4~10). 양수 = 직렬이 더 좋음. G_m(1) = P-U(η=1) 기존 셀의 격차(run 0~9).
- 기존 셀(재사용): `Checkpoint/Results/EXP/H12/final_uniform`(S-U), `final_uniform_parallel`(P-U η=1), run 0~9.

## 1. 0단계 (무비용 분석; 기존 S-U·P-U 셀만 사용)
정의: 직렬 기준선 R_m = S-U의 M_m(라운드 4~10, run 평균). 병렬 후반 L_m = P-U의 라운드 18~20 평균 M_m. 직렬 후반 = S-U의 라운드 18~20.
- 라운드별 곡선 M1, M2, global_loss: run 평균±표준편차(1~20라운드)를 표로 보고.
- 상승 중(m): run별 [P-U의 라운드 18~20 평균 − 라운드 11~13 평균] 의 95% CI 하한 > 0 이고 평균 ≥ 0.1%p. 아니면 "평탄".
- 도달 라운드: P-U의 run 평균 M1(라운드별 10클라 평균)이 R_M1 이상이 되는 첫 라운드 (없으면 "도달 못 함"). M2도 동일하게 R_M2 기준(라운드별 최저 AUC의 run 평균).
- 후반 격차: S-U − P-U (라운드 18~20 평균, 짝지은 run)의 평균과 90% CI.
- 클라이언트별 격차: 라운드 4~10, run 평균 Δ = P-U − S-U를 클라이언트별로. 약한 클라이언트(S-U 평균 AUC 하위 2개)가 전체 하락 합계에서 차지하는 비율은 기술통계만(판정 불사용).
- **멈춤 조건(설계 변경 후보)**: (i) L_M1 ≥ R_M1 − 0.3 이고 L_M2 ≥ R_M2 − 1.0 (병렬이 20라운드에 직렬 수준에 도달), 또는 (ii) 직렬 후반 대비 병렬 후반 격차가 M1 90% CI ⊂ (−0.3, 0.3)이고 M2 90% CI ⊂ (−1.0, 1.0) (격차가 시간이 지나며 사라짐). 둘 중 하나라도 성립하면 1단계로 가지 않고 멈춰 보고한다.
- 가설 선별 판정(기술적, 1단계 진행 여부 불변):
  - H-A 후보 강화: 병렬이 두 지표 중 하나라도 "상승 중"이고 후반 격차(M1)가 G_M1(1)의 50% 이하.
  - H-A 후보 약화: 두 지표 모두 "평탄"이고 후반 격차(M1)가 G_M1(1)의 50% 초과.
  - 그 외: 어느 쪽도 아님(판정불가).

## 2. 1단계 셀 (모두 균등평균 hybrid, 20라운드, 로깅 켬)
| 태그(디렉터리) | 데이터 | 토폴로지 | η | run |
|---|---|---|---|---|
| n_S_log | non-IID | 직렬 | – | 0~4 (로깅용 재실행; AUC는 기존 S-U와 일치해야 함) |
| n_P1_log | non-IID | 병렬 | 1 | 0~4 (로깅용 재실행; 기존 P-U와 일치해야 함) |
| n_P2 | non-IID | 병렬 | 2 | 0~9 |
| n_P5 | non-IID | 병렬 | 5 | 0~9 |
| i_S | IID-10 | 직렬 | – | 0~4 (사용자 확정 결정 2) |
| i_P1 | IID-10 | 병렬 | 1 | 0~4 |
| i_P5 | IID-10 | 병렬 | 5 | 0~4 |
- η: 병렬 집계 `W_g ← W_start + η·(mean − W_start)` (η=1은 기존 `mean` 그대로 사용, 부동소수 재조합 안 함). 직렬에는 적용 안 함.
- 로컬 early stop 끄기 대조는 이번에 하지 않는다(사용자 확정 결정 3); 에폭·스텝 로깅만.
- 로깅: 클라이언트별 실제 에폭 수(`training_tracking.pkl` 길이)와 스텝 수(에폭×배치 수), 로컬 모델의 라운드 시작 global 대비 이동거리(직렬도 직전 모델이 아닌 라운드 시작 global 기준), 집계 후 global의 라운드 시작 대비 이동거리, 로컬 모델 간 평균 쌍별 거리. 로깅은 난수·학습 경로에 영향을 주지 않아야 한다(단위 검증).
- IID 설정: `Configuration/scen2-nba-iot-10clients.json`(data_path = `IID-10-Client_Data`).
- 발산: 어떤 run이든 라운드 ≥5에서 10클라 평균 AUC < 0.90이면 그 셀은 "발산"으로 기록하고 그 셀의 남은 run은 중단(다른 셀은 계속). 멈춤 사유 아님. 발산 셀은 판정에서 "안 닫힘, 발산"으로 취급하되 "이동거리 맞춤" 조건은 충족하지 못한 것으로 본다.
- 일치 검사(멈춤 조건): n_S_log/n_P1_log의 run 0~4 `global_auc`, `join_clients`가 기존 S-U/P-U와 |AUC 차| ≤ 1e-9로 일치하지 않으면 멈춘다.

## 3. H-A 판정 (η 셀 vs 직렬, run 0~9 짝지은)
지표 m별로 d_m = P-U(η) − S-U (%p, run별).
- 지표 상태(m, η):
  - **닫힘**: 90% CI가 (−δ_m, +δ_m)에 포함(동등), 또는 [95% CI 하한 > 0 이고 평균 ≥ δ_m] (병렬이 직렬보다 오히려 좋음).
  - **부분 닫힘**: 닫힘이 아니고 G_m(1) > 0이며 G_m(η) ≤ 0.5·G_m(1).
  - **안 닫힘**: 그 외.
- 셀 상태(η): 두 지표 모두 닫힘 → "닫힘"; 둘 다 {닫힘, 부분}이고 닫힘 아님 → "부분 닫힘"; 그 외(발산 포함) → "안 닫힘".
- 이동거리 맞춤(η): 집계 후 global 이동거리(라운드 4~10, run 평균)의 비 P-U(η)/S-U(로깅 셀 n_S_log run 0~4)가 [0.67, 1.5] 안. 비는 run별 평균 이동거리의 비로 계산.
- **H-A 지지**: 어떤 η ∈ {2,5}에서 (셀 상태 ∈ {닫힘, 부분 닫힘}) 이고 (이동거리 맞춤).
- **H-A 기각**: 발산하지 않은 η 중 이동거리 맞춤인 것이 하나 이상이고, 발산하지 않은 모든 η가 "안 닫힘"이며, 그중 이동거리 맞춤인 η가 존재.
- 그 외: **H-A 판정불가**(예: 닫혔으나 이동거리 불일치, 안 닫혔으나 이동거리도 안 맞음/발산).
- 민감도(판정 불사용): 라운드 11~20 지표, 이동거리 비, 라운드별 곡선.

## 4. H-B 판정 (IID 대조, run 0~4)
- 동일 run 0~4의 비-IID 격차: G^n_m = mean[S-U(기존) − P-U η=1(기존)] (run 0~4). IID 격차: G^i_m = mean[i_S − i_P1] (run 0~4).
- 천장 규칙: i_S와 i_P1의 M1이 모두 ≥ 99.5이면 천장효과로 H-B는 "판정불가".
- 격차 작음(m): G^n_m ≥ δ_m 일 때만 정의; G^i_m < 0.5·G^n_m 이거나 [i_S − i_P1]의 90% CI ⊂ (−δ_m, +δ_m). G^n_m < δ_m 이면 판정불가.
- 드리프트 측도: 상대 드리프트 rd = (로컬 모델 간 평균 쌍별 거리) / (로컬 모델의 평균 이동거리), 라운드 4~10 평균, run별. 비-IID(n_P1_log run 0~4) vs IID(i_P1 run 0~4)의 차 rd_n − rd_i를 두 집단 각각 재표집한 부트스트랩(95% CI)으로 계산. "유의하게 큼" = 95% CI 하한 > 0.
- **H-B 지지**: M1, M2 모두 "격차 작음"이고 rd가 "유의하게 큼".
- **H-B 기각(주요 원인 아님)**: M1, M2 중 하나라도 G^i_m ≥ 0.5·G^n_m 이고 (G^n_m ≥ δ_m) (IID에서도 격차가 비슷하게 남음).
- 그 외 **H-B 판정불가**.
- 보조(판정 불사용): i_P5 vs i_S 격차, 원시 쌍별 거리.

## 5. H-C 판정
- 클라이언트당 평균 에폭 수와 스텝 수(라운드 4~10, 로깅 셀 n_S_log vs n_P1_log, run 0~4, 선택된 클라이언트별 평균): 큰 값/작은 값 ≥ 1.5이면 **H-C 지지**, 아니면 **H-C 약함**. 라운드 1~20 평균도 병기(판정 불사용).
- 클라이언트별로도 에폭 수를 표로 보고(기술통계).

## 6. 종합 권고 (우선순위 없이 병기, 근거 수치 포함)
- H-A 지지 → 해법 후보: 서버 학습률 η, 서버 모멘텀, 라운드 수 증가.
- H-A 기각 & H-B 지지 → 드리프트 완화(FedProx류, SCAFFOLD, 서버 모멘텀, 로컬 에폭 축소).
- 둘 다 아님 → H-C·미확인 원인, 추가 대조(로컬 early stop 끄기 등)를 별도 사전 규칙으로.
- 여러 개가 부분적으로 성립하면 기여 비율(격차 감소율 1−G_m(η*)/G_m(1), IID 격차비 G^i_m/G^n_m)을 수치로 보고. 서로 더해지는 값이 아님을 명시.
- 한계(반드시 명시): 단일 분할, run 10(IID 5), 균등평균 한정, 가설별 단일 조작 변수(복합 원인 가능), IID 데이터는 크기·구성도 달라 H-B 외 요인이 섞일 수 있음, 원인 확정은 확인 분할 재현 후.

## 7. 멈춤 조건과 시간
- 0단계 멈춤 조건(§1), 단위 검증 실패, 기존 셀과 불일치(§2 일치 검사), sol "문제 있음", 예상 시간 1.5배 초과, 디스크/GPU 오류, 이 규칙으로 판정 불가한 경계.

- 본 실행 시작 전 예상 시간을 보고하고, 실제 경과가 그 1.5배를 넘으면 멈춘다.

## 8. 단위 검증 (본 실행 전 모두 통과)
(a) η=1이 기존 P-U 셀 run 0 앞 2라운드와 AUC 차 0(≤1e-9)·join 동일; (b) η 공식이 수치로 `start + η(mean−start)`와 일치; (c) 로깅 on/off 동일 궤적(AUC 차 0); (d) IID 설정이 IID-10 데이터를 읽음(경로, 행 수, 비-IID와 다름); (e) 병렬 첫 클라이언트 == 직렬 첫 클라이언트(로컬 state 차 <1e-6); (f) 로깅값 점검(에폭 수가 pkl과 일치, 쌍별 거리·이동거리 합성 검산).
