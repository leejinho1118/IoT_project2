# 실험 계획 초안 (미승인, 구현 전)

## 단계
1. **진단** (결과 불변): 라운드별 α 분포(max/min, 정규화 가중치 엔트로피), 클라이언트 학습 시작 가중치와 직전 global의 L2 거리, 참가 순서별 MSE를 로깅. 직렬 체인과 α 평평함 여부를 확정.
2. **스윕**: 아이디어 1의 (β, p) 격자. 현행 MSEAvg와 FedAvg를 양 끝점으로 포함.
3. **후보 비교**: 스윕 최적 설정 대 아이디어 3, 7, 8.

## 평가 기준 (결정 필요)
- 같은 data seed, 같은 클라이언트 선택 시퀀스로 짝지어 비교 (random.sample seed 고정).
- 반복 횟수: 기존 5회는 부족. Sonnet은 최소 10회, codex는 20~30회 권장. 시간 비용과 함께 결정.
- 보고 라운드: 마지막 라운드와 최고 라운드를 둘 다 보고 (논문 기준 미확인).
- 지표: 클라이언트 AUC 평균 + 최저 클라이언트 AUC + 표준편차. 짝지은 t검정 또는 부트스트랩.
- dev에 과적합하는 방법(아이디어 7 등)은 dev를 선택용/보고용으로 분할해 확인.

## 제약과 주의
- 논문 하이퍼파라미터는 고정, 집계 규칙만 변경. 직렬 체인은 `main.py`·`client_trainer.py` 영역이라 수정 여부는 별도 결정 (수정하면 "재현 코드"와 달라짐).
- 비용 참고: 재현 한 번(6조합 × 5회)에 상당 시간이 걸렸으므로 조합 수를 줄여 SAE-CEN+MSEAvg 계열 위주로 돌리는 것을 권장.
- 문헌(FedAvgM, q-FFL, model soup)은 Sonnet이 기억으로 언급한 것이라 인용 전 확인 필요. 웹 조사는 하지 않았음.
