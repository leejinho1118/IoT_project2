# KCI 논문 기준 재정리 (2026-11-09, 초안·미승인)

KCI 학술지별 심사 기준은 확인하지 않았고 일반적인 경향에 근거함. 투고처가 정해지면 해당 학술지 양식과 분량을 확인할 것.

## 기준이 바뀐 점
- 이전: 구현이 쉽고 평균 AUC를 올릴 만한 순서.
- 지금: 문제 정의 → 제안 → 소거 실험 → 통계적 일관성이 서는 순서. 평균 AUC 향상(재현 기준 MSEAvg−FedAvg=+0.56%p)이 작아도, 안정성·공정성·분석으로 기여를 주장할 수 있는지가 핵심.

## 아이디어 재평가
| 논문 이야기 | 근거 아이디어 | 평가 |
|---|---|---|
| 재구성 오차와 샘플 수를 결합한 비-IID 적응형 가중 집계 | 1 | 안전하지만 참신성 약함. **기준선/소거 실험 축으로 사용** |
| 클라이언트별 정규화와 최저 클라이언트 성능 보장(공정성) | 4 | 문제 정의가 분명. 평균이 안 올라도 최저 AUC·분산으로 주장 가능 |
| 탐지기(잠재 Centroid)와 정렬된 가중 | 6 | 참신성 최고. SAE-CEN 특화. hybrid 전용이라 AE에는 해당 없음 |
| 부분 참여 환경의 분산 감소(모멘텀/EMA) | 8 | 안정성 주장에 적합, 실험 비용 낮음 |
| 직렬 학습 편향 분석 | 진단 로깅 | 단독 논문보다 분석 파트로 사용. 서술 주의 |
| 가중치 상한 / trimmed mean / 부트스트랩 안정도 | 2, 10, 5 | 독립 기여가 약해 소거 실험 변형이나 부록으로 |

## 제안 구성 (안)
1. **문제 정의:** 기존 MSEAvg의 한계를 데이터로 제시. 진단 로깅으로 α 분포(평평/쏠림), 샘플 수 무시, dev 스케일 불일치의 영향을 보여줌. (진단 결과에 따라 문제 정의 문장이 달라짐)
2. **제안 방법:** 아래 중 하나를 중심으로 (미결정)
   - A. 잠재공간 정렬 가중 (참신성 중심)
   - B. 클라이언트 공정성 가중 (문제 정의 중심)
3. **비교 대상:** FedAvg, FedProx, 기존 MSEAvg, 아이디어 1 최적 설정.
4. **소거 실험:** n_i 항(β), 점수 민감도(p), 제안 요소 유무.
5. **평가:** 평균 AUC, 최저 클라이언트 AUC, 표준편차. 반복 10회 이상, 짝지은 검정(같은 data seed와 선택 시퀀스). 마지막/최고 라운드 둘 다 보고.
6. **일관성 검증:** 레포에 있는 IID/non-IID × 10/50 클라이언트 4개 분할 모두 사용. 데이터 폴더 `Data/N-BaIoT/{IID-10,IID-50,noniid-10,nonIID-50}-Client_Data`.

## 리스크
- 평균 AUC가 거의 안 오를 수 있음 → 안정성/최저 성능/분석 중심으로 서술을 준비.
- 50 클라이언트 설정은 실행 시간이 큼. 비용 확인 후 범위 결정.
- 직렬 학습 체인을 수정하면 "논문 재현 코드"와 달라짐. 수정 여부는 별도 결정(수정 전후를 둘 다 보여주는 방식도 가능).
- 재현이 논문과 ≤0.9%p 일치했다는 점은 기준선 신뢰도에 도움이 되지만, 보고 라운드 기준은 아직 확인하지 못함.

## 결정 대기
- 제안 방법의 중심: A(잠재공간 정렬) 또는 B(공정성) — 또는 진단 로깅 후 결정.
