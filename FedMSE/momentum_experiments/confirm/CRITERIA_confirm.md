# FedAvgM 확정 대조 실험 사전 기준 (2026-11-21)

## 고정 설정

모든 방법은 새 실행기(`run_confirm.py`)의 동일 코드 경로를 사용한다. 비IID는 `Configuration/repro-noniid-10clients.json`, `data_seed=1234`, run 0–9이고, IID는 `Configuration/repro-noniid-10clients-iidified.json`, `data_seed=1234`, run 0–4다. 기본 비교는 20라운드이며 각 run 내 방법 간 라운드별 참여자 시퀀스를 같게 한다. run별 난수 시드는 run 번호×10000이다. 클라이언트 10개 중 라운드마다 5개, hybrid 로컬 학습, 최대 100 epoch, patience=3, lr=1e-5, batch=12를 사용한다.

## 방법

- B1: 새 실행기로 MSEAvg 재실행.
- B2: 새 실행기로 sample-count 가중 FedAvg.
- M: 새 실행기의 FedAvgM, 모멘텀 0.9 및 서버 학습률 1.0. 이전 실행기의 FedAvgM 구현이 `v_t=0.9v_(t-1)+(FedAvg_t-global_t)`, `global_(t+1)=global_t+v_t`였음을 확인했고, 이번에는 동일 수식을 공통 코드 경로로 실행한다. 이전 결과는 재사용하지 않는다.
- C1: 모멘텀이 없는 FedAvg에 서버 학습률 η=10 적용. 이는 모멘텀 0.9의 정상상태 유효 스텝 크기 1/(1−0.9)=10에 대응하는 설정 대조다.
- C2: 비IID MSEAvg를 40라운드 학습해 40번째 라운드 AUC를 참고 기록한다. 라운드 수가 달라 B1과 직접 짝지은 주 판정으로 취급하지 않는다.

위 방법들을 비IID와 IID 모두에서 실행한다. C2는 비IID 참고 결과만 실행한다. 모든 방법은 동일한 분할·run 안에서 같은 참여자 시퀀스를 쓴다.

## 지표와 통계

주 지표는 최종 라운드의 클라이언트 평균 AUC다. 방법별 run 평균 AUC와 각 대조 대비 FedAvgM의 paired 차이 `M−대조`(%p), 양측 95% t 구간(df=n−1), 완료된 짝 런 수를 기록한다. IID는 run 0–4, 비IID 0–9로 짝짓는다. C2는 40라운드 최종 평균만 보고하며 라운드 불일치 때문에 paired 주 대조로 해석하지 않는다. 다중 비교 보정은 하지 않는다.

## 사전 판정

1. 재현 참고: B1 비IID 평균이 기존 H12 MSEAvg run 0–9 평균에서 ±0.3%p 이내인지 기록한다.
2. 비IID FedAvgM 이득 확인: M−B1 평균이 +0.5%p 이상이고 95% 구간 하한이 0보다 커야 한다.
3. 고유 효과 대 유효 스텝 크기: M−C1의 95% 구간 하한이 0보다 크면 ‘모멘텀 고유 효과’. 구간이 0을 포함하면 ‘유효 스텝 크기 효과와 구분되지 않음’으로 기록한다. 이는 설정 비교의 명칭이며 기제의 인과 설명은 하지 않는다.
4. IID 안전 기준: M−B1 평균 차이가 −0.3%p보다 나쁘지 않아야 한다.

실험 실행 전 본 문서를 SHA-256으로 고정한다. 수정이 필요하면 원문을 고치지 않고 `DEVIATIONS_confirm.md`에 시각, 변경 사항, 사유를 기록한다.
