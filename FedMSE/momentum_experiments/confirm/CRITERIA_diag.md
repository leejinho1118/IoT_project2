# 진단 비교 사전 질문 (2026-11-24) — 탐색·사후(post-hoc), 신규 실행 없음, 기존 로그만
이전 동결 문서(CRITERIA_damped/difficulty 등)는 수정하지 않는다. 작성자는 이미 이득 부호와 난이도 결과를 본 뒤 작성했으므로 확증이 아니다.

## 사용 가능한 로그
라운드별 `global_auc`(클라이언트 평균), `diag2.global_disp`(서버가 실제로 움직인 거리 ‖w_t−w_{t−1}‖), `diag2.local_disp`(참여 클라이언트별 이동), `diag2.E`=global_disp/평균 local_disp. D0의 global_disp = 평균 변화량 ‖Δ_t‖. (D1·D2는 `guard.delta_norm`=‖Δ_t‖도 있음.)

## 비교(고정)
셀마다 D0·D1·D2(있는 것)를 같은 run끼리: (a) 라운드별 AUC 곡선(런 평균)에서 R1~5 평균, R6~15 평균, R31~40 평균; (b) 라운드별 global_disp의 R1~5·R6~15·R31~40 중앙값과 D0 대비 비율; (c) E의 같은 구간 중앙값; (d) 라운드 간 AUC 낙하 횟수(R2 이후 전 라운드 대비 AUC가 2%p 이상 떨어진 라운드 수, 런 평균).
D1은 10런 셀, D2는 run 10 한 런. D2 비교는 같은 run 10만 사용(D0·D1도 run 10 기준 값을 별도 열로).

## 가설별 사전 패턴
- H_over("쉬운 데이터에서 오버슈트"): D1의 global_disp 비율(대 D0)이 초반(R1~5)에 데이터셋 간 비슷하게 크고(예: 2배 이상), 이득이 음인 데이터셋(ToN·CIC)에서는 D1 낙하 횟수가 D0보다 많고 R6~15 AUC가 D0 이하로 떨어지며, D2는 그 낙하가 줄어든다.
- H_dir("느린 데이터에서 방향 평균이 도움"): 이득 양인 데이터셋(N-BaIoT)에서 D0의 R1~15 AUC 상승이 더 완만(R6~15 AUC가 R31~40보다 뚜렷이 낮음)하고 D1·D2가 그 구간을 앞당기며, D2도 D1과 비슷한 이득을 보이고 global_disp 비율이 D1보다 훨씬 작다.
- 두 패턴 모두 아니거나 혼재하면 "구분 불가"로 쓴다. 임계(2배, 2%p)는 관례값이며 결과 후 변경 금지. 판정 없이 패턴 부합 여부만 서술.

## 한계
D2는 n=1, 데이터셋과 난이도가 겹침, 클라이언트 평균 AUC는 클라이언트별 분포를 숨김, global_disp는 모델 전체 L2 거리라 층별 차이를 못 봄. 로그에 없는 것(층별 이동, 클라이언트별 AUC 곡선, 모멘텀 누적 v의 크기)은 필요 시 추가 로깅 제안으로만 적는다(실행 안 함).
