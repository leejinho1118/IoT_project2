# 모멘텀 이득 vs 난이도 탐색 기준 (2026-11-24) — 탐색용, 신규 실행 없음, 기존 결과만 사용
가설(이론 근거, 이전 세션 가설): 모멘텀은 D0(MSEAvg)가 느리게 수렴해 개선 여지가 클 때만 이득이고, 이미 빨리 수렴하면 걸음만 커져 오버슈트로 불리하다.
**공개 주의: 작성자는 이 문서 동결 전에 D1·D2의 셀별 이득 부호를 이미 보았다(RESULTS_damped11.md 등). 따라서 이 분석은 사후 탐색이며 확증이 아니다. 임계값은 아래처럼 이득과 무관한 이론적 기준으로만 정했다.**

## 난이도 정의(고정)
셀(데이터셋·data_seed)마다, D0 셀의 존재하는 모든 완료 런(40라운드)에서 클라이언트 평균 AUC(%)가 처음으로 95.0 이상이 되는 라운드(라운드 1부터 셈, 끝까지 도달 못하면 41로 취급)의 **중앙값** = T95.
- 쉬움: T95 ≤ 3. 어려움: T95 ≥ 4.
- 임계 3·95%는 "라운드 40의 약 1/10 안에 95% 도달"이라는 임의 관례값이며 이득 부호를 보고 고르지 않았다. 결과 후 변경 금지.

## 예측(사전)
쉬움 → 이득(D1−D0, D2−D0) ≤ 0, 어려움 → 이득 > 0. 이득은 R31~R40 클라이언트 평균 AUC 평균의 짝차(%p): D1은 D1 셀과 D0 셀의 공통 run 짝차 평균, D2는 run 10 한 런 짝차(n=1).
## 보고
셀마다 T95, 분류, D1 이득, D2 이득, 부호 일치 여부를 데이터셋별로 따로 표로. 일치 개수만 세고 통과/불통과 판정 없음. 셀이 소수(대부분 D2는 n=1)이고 난이도와 데이터셋이 겹쳐 있어(N-BaIoT 전부 어려움, ToN 전부 쉬움이면) 난이도와 데이터셋 효과를 분리 못 함을 한계로 명시.
