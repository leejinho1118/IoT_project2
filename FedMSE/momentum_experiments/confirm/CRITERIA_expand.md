# FedAvgM 확대 검증 사전 기준 v2 (2026-11-21)
v1은 실행 전에 SOL(gpt-6.2-sol) 독립 검토에서 "모멘텀 고유 효과는 증명 불가(부분적)" 판정을 받아 아래로 대체했다(실행 이력 없음).

목적: N-BaIoT 비IID에서 FedAvgM(서버 모멘텀) 이득이 (a) 서버 이동량 증가만으로 설명되는지, (b) 학습 부족 보완인지, (c) β 민감도를 가린다. ToN-IoT·CIC는 로컬 데이터 없어 범위 밖. 결론은 "이 분할·설정에서"로 한정한다.

## 고정 설정
confirm과 동일(비IID config, data_seed=1234, run 0–9, 5/10 참여, hybrid, 최대 100 epoch, patience=3, batch=12, 시드=run×10000, serial 토폴로지, 방법 간 참여자 시퀀스 동일). 실행기에 `--momentum`, `--lr`만 추가하며 기본값(0.9, 1e-5)은 기존과 비트 동일. 모든 셀을 새 실행기로 새로 돌린다(기존 결과 재사용 안 함). 출력은 새 cell 이름 아래. 모든 셀 40라운드 실행, R20·R40을 각각 평가(같은 시드이므로 R20은 20라운드 실행과 동일 경로). 기록에 실제 적용된 β·η·lr을 남긴다.

## 셀 (각 10런, 40라운드)
lr=1e-5:
- A: FedAvg(β=0, η=1)
- B: FedAvgM(β=0.9, η=1)
- C3: FedAvg η=3 / C10: FedAvg η=10
- E: **이동량 맞춤 대조** — FedAvg를 매 라운드 B의 같은 run·라운드 global_disp로 재스케일(`--disp_target_cell`, B 로그 필요)
- X1: FedAvgM β=0.5 / X2: β=0.99
lr=5e-5: A′, B′, E′(A′·B′와 같은 정의).
(고정 로컬 step 예산 대조는 구현 비용 때문에 이번에 하지 않으며 한계로 보고한다.)

## 지표·통계
주 지표 = 해당 라운드(R20, R40) 클라이언트 평균 AUC. 짝 비교는 같은 run끼리 차이(%p), 양측 95% t 구간(df=n−1). 실질적 차이 한계 δ=0.3%p. 판정어: 하한>δ=실질 우월, 하한>0=우월(소폭), 구간 전체 ⊂ ±δ=실질 동등, 그 외 미결. 발산(R5+ 평균 AUC<0.90)·미완료 런은 제외하지 않고 개수를 보고하며, 미완료 run은 해당 짝에서만 제외하고 n을 표기한다.

## 확증 대비(Holm 보정, 3개)
H1: B−E at R20(lr1e-5), H2: B−E at R40(lr1e-5), H3: B′−E′ at R20(lr5e-5). 이동량이 같은 조건에서도 모멘텀이 우월한가. 나머지는 탐색적(보정 없음, 그렇게 표기).

## 사전 판정 문장
1. H1~H3 모두 Holm 보정 후 하한>0 → "이동량을 맞춰도 모멘텀 이득이 유지되어 모멘텀(과거 업데이트 누적 방향)의 기여와 일관됨". 하나라도 아니면 "고유 효과 미확정".
2. 이득이 B−E는 0과 구분 안 되는데 B−A는 양수 → "이득은 서버 이동량 증가로 설명됨".
3. 학습 부족 가설: A′−A, A40−A20 각각 +1.0%p 이상이면 "FedAvg 부족이 일부 원인". 이어서 격차 변화 `(B′−A′)−(B−A)`, `(B40−A40)−(B20−A20)`를 같은 run 짝으로 95% 구간 보고(격차 축소 여부).
4. β 민감도: X1, X2, B 최종 AUC를 표로만 보고. 최적 β 선택·재튜닝 금지.
5. 결과를 본 뒤 설정·기준 변경 금지. 필요 시 `DEVIATIONS_expand.md`에 기록.
