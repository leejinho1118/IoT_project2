# 새 데이터 분할 반복 사전 기준 (2026-11-22)
목적: 직접 대조(CRITERIA_direct.md, data_seed=1234 통과)의 MSEAvg vs MSEAvg+모멘텀 비교가 다른 분할에서도 유지되는지 확인.

## 분할의 의미(한계)
`load_clients`에서 data_seed는 클라이언트 순서와 각 클라이언트 내부 정상 데이터의 셔플(train/valid/dev/test 구간)만 바꾼다. 클라이언트별 원본 파일(비IID 분포)은 고정이다. 따라서 "새 분할"은 같은 N-BaIoT 비IID 데이터의 새 내부 분할이며, 새 데이터셋·새 비IID 분포가 아니다. 다른 데이터셋(ToN·CIC)은 이 단계 다음.

## 설계
- 방법: D0=MSEAvg(역MSE 가중, variant `mse`), D1=MSEAvg+모멘텀(β=0.9, η=1, variant `mse_m`). 가중 동일.
- data_seed ∈ {2024, 4321, 7777}(1234 제외). 분할마다 run 10–19(시드 run×10000), parallel 토폴로지, 40라운드, patience=3, batch=12, 최대 100 epoch, 5/10 참여, 같은 분할 안에서 두 셀의 참여 순서 동일(사후 검증).
- 판정 셀(lr=1e-5): 분할마다 10런×2방법.
- 탐색 셀(lr=5e-5, 하이퍼파라미터 민감성): 분할마다 run 10–14(5런)×2방법. 판정에 쓰지 않고 별도 보고(5런이라 구간이 넓음).

## 주 지표·판정
분할별로 따로: 런별 R31~R40 클라이언트 평균 AUC의 평균, 짝차 D1−D0, 양측 95% t 구간. **통과 조건 = lr=1e-5에서 세 분할 모두 구간 하한 > +0.3%p.** 하나라도 못 넘으면 불통과(어느 분할인지 명시). 분할 결과를 합치지 않는다. 발산(R5 이후 평균 AUC<0.90)은 제외하지 않고 분할·셀별로 집계. 보조: R20, R40 짝차, 0.97 유지 도달 라운드(미도달 수), 학습 스텝 총합.
