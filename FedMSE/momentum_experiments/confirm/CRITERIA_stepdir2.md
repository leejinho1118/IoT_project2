# 걸음 맞춤 대조 + 방향 로깅 소규모 실험 (2026-11-24) — 탐색용, 확증 아님
이전 동결 문서는 수정하지 않는다. 작성자는 ToN·CIC에서 D1이 불리하고 D2도 이득이 없다는 기존 결과를 이미 알고 있다.

## 셀·런 (총 8런, 모두 run 10 한 런, data_seed=1234, parallel, lr=1e-5, 40라운드, patience 3, batch 12)
데이터셋 ton, cic_km 각각 4런:
- D0L: variant mse(MSEAvg) + 방향 로깅(기존 D0 run 10과 같은 경로여야 함)
- D1L: variant mse_m + 방향 로깅
- D2L: variant mse_dm + 방향 로깅
- D0M: variant mse + `--disp_target_cell`로 같은 run·라운드의 **D1 셀(기존 D1_ton_s1234 / D1_cic_km_s1234 run 10)의 global_disp**에 맞춰 매 라운드 이동량을 재스케일(방향은 D0의 평균 델타 그대로, 크기만 D1과 동일) + 방향 로깅
재현 점검: D0L·D1L·D2L의 라운드별 평균 AUC가 기존 run 10 기록과 1e-6 이내 일치해야 한다(로깅이 계산 경로를 바꾸지 않음의 확인). 불일치 시 DEVIATIONS_stepdir2.md에 기록하고 해당 비교는 "재현 실패"로 표기.
N-BaIoT는 이번 범위가 아니다(기존 N-BaIoT 대조는 CRITERIA_stepdir.md·RESULTS_expand.md).

## 방향 로깅(diag2에 추가, 계산 경로 불변)
라운드마다 참가 클라이언트 델타(로컬 학습 후 − 라운드 시작 모델)에 대해: pair_cos(쌍별 코사인 평균), cos_mean(각 델타와 평균 델타(가중 평균 아님, 단순 평균)의 코사인 평균), cos_prev(이번 라운드 단순 평균 델타와 직전 라운드 평균 델타의 코사인; 1라운드는 null).

## 사전 패턴 (R31~40 클라이언트 평균 AUC 평균, 같은 run, 단위 %p)
손실 L1 = D0L − D1L (D1이 D0보다 나쁜 양; 양수면 D1 불리). 대조 손실 LM = D0L − D0M.
- "걸음 크기 설명": L1 > 0.3이고 LM ≥ (2/3)·L1.
- "방향(누적) 설명": L1 > 0.3이고 LM ≤ (1/3)·L1.
- 그 사이 또는 L1 ≤ 0.3: "혼재/판정 불가".
- 보조: R5 이후 AUC 낙하(전 라운드 대비 2%p 이상 하락) 횟수를 D0L/D1L/D2L/D0M별로 보고. cos_prev 중앙값(R2~40)이 0.3 미만이면 "라운드 간 방향 불안정", 0.6 이상이면 "안정"으로 서술(데이터셋·방법별 표). 임계(0.3, 1/3, 2/3, 0.6)는 관례값, 결과 후 변경 금지.
- n=1이라 구간·유의성 없음, 우연일 수 있음. 해석은 서술이며 인과 확정 아님.
