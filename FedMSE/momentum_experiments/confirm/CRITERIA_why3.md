# ToN 호스트별 라운드 곡선 분석 (2026-11-24) — 탐색·사후, 신규 실행 없음, 기존 로그만
이전 동결 문서는 수정하지 않는다. 작성자는 손해 호스트(.195/.190/.152)와 천장 호스트의 최종 AUC 차이는 이미 보았고, 라운드별 곡선·낙하 시점은 아직 보지 않았다.

## 대상
- 셀: ToN data_seed 1234, 2024. D0·D1은 run 10–19(10런 짝), D2는 run 10, D0M·D0L·D1L·D2L은 시드 1234 run 10(D1L은 guard 포함). 라운드별 호스트 AUC는 로그의 `global_auc`(전체 8호스트에 대한 글로벌 모델 AUC)를 `devices` 순서로 사용.
- 손해 호스트 = 192.168.1.195, .190, .152. 천장 호스트 = 최종(R31~40) D0 AUC ≥ 99%인 호스트(.180, .184, .194, 172.17.0.5). .193은 중간으로 제외.

## 지표(고정)
- 낙하 사건: 호스트·런에서 라운드 t≥2의 AUC가 직전 라운드보다 2%p 이상 하락한 횟수. 이탈 라운드: 같은 run·라운드의 D0 호스트 AUC보다 처음 3%p 이상 낮아진 라운드(D1·D2·D0M 대비 D0).
- 걸음 대비 낙하: 라운드별 호스트 AUC 변화(%p)와 같은 라운드 서버 이동거리 global_disp(그 run D0 이동거리 중앙값 대비 비율)의 스피어만 상관, 손해군·천장군 각각(런·라운드 풀링, 풀링이라 독립 아님을 명기).
- 누적 정점: D1에서 global_disp(= ‖v‖, η=1)가 그 run의 75퍼센트 이상인 라운드를 정점 라운드라 한다. 낙하 사건이 정점 라운드 또는 그 다음 라운드에서 일어난 비율(기대치 약 45%: 정점이 25%라 정점+직후 라운드 포함).
- 회복: 이탈 후 R31~40 평균 AUC가 D0의 R31~40 평균 AUC에서 3%p 이내이면 회복.
- D0M 비교: 같은 호스트의 낙하 횟수와 이탈 라운드를 D1과 D0와 비교(시드 1234 run 10만).

## "근한계 호스트가 모멘텀 진동에 취약" 지지 패턴
(i) D1의 손해 호스트 낙하 횟수(런 평균)가 천장 호스트의 3배 이상(천장은 거의 0). (ii) 손해군에서 스피어만 ρ(걸음 비율, AUC 변화) ≤ −0.3이고 천장군은 |ρ|<0.2. (iii) 낙하의 정점+직후 라운드 비율 ≥ 60%. (iv) D0M에서도 손해 호스트가 낙하(D1 횟수의 절반 이상)하고 D0는 낙하가 거의 없음. (v) D2 낙하 횟수가 D1의 절반 이하. 다섯 중 4개 이상이면 "부합", 2개 이하면 "불부합", 그 사이는 "혼재". 임계는 관례값, 결과 후 변경 금지.
