# FedExP를 MSEAvg 위에 얹는 사전등록 시험 설계 (2026-11-24) — 실행 전 동결, 이 문서가 확증 시험의 기준
이전 동결 문서는 수정하지 않는다. 작성자는 지금까지 D0/D1/D2 결과를 모두 보았다(FedExP 규칙은 우리 데이터를 보고 고른 것이 아니라 문헌 조사 B에서 선정; 선정 사유 lit_B/COMPARE_litB.md).

## 1. 원문 확인(사람식 정독, 원문: arXiv 2301.09604 ICLR 2023, lit_B/pdf/2301.09604.txt의 Algorithm 1·식(9)·§3.3·부록 D.3을 직접 읽음; 수식 조판이 추출 텍스트에서 흩어져 분수는 줄 단위로 재구성함 — 렌더된 PDF 그림은 보지 않음)
- 클라이언트 델타: Δ_i^(t) = w^(t) − w_i^(t,τ) (Alg.1 9행). 평균 Δ̄^(t) = (1/M)ΣΔ_i (11행).
- **서버 걸음: η_g^(t) = max{ 1, Σ_{i=1}^{M} ‖Δ_i^(t)‖² / ( 2M ( ‖Δ̄^(t)‖² + ε ) ) }** (식 (9), Alg.1 11행). 갱신 w^(t+1) = w^(t) − η_g^(t) Δ̄^(t) (12행).
- 부분 참여(§3.3): "η_g를 참여한 클라이언트의 업데이트만으로 계산, 평균과 나눗셈은 참여 클라이언트에 대해서만".
- ε(§3.3): "분모에 작은 양수 ε를 더해 폭주를 막는다. ε가 충분히 크면 FedAvg로 환원".
- ε 상수: 논문은 하나의 값을 주지 않는다. 신경망 실험은 ε 격자 {10^-3, 10^-2.5, 10^-2, 10^-1.5, 10^-1}를 50라운드 학습 정확도로 튜닝(부록 D.3), 최적은 CIFAR-10/100·CINIC이 10^-3, EMNIST가 10^-1, 합성 데이터는 ε=0(조건 (6) 성립). 즉 "논문 값 그대로"에는 선택이 필요하다 → 아래 설계 결정 D-ε.
- 이 문서가 직접 확인하지 못한 것: 식 (8)·정리의 유도, 부록의 비볼록 논의 세부. 이론(식 (6) 가정)은 볼록·과대매개변수 설정이며 우리 오토인코더·비IID에서 성립한다는 보장은 원문에서 못 찾음.

## 2. 우리 설정으로의 대응 — 모두 설계 결정(논문이 정해주지 않은 것은 [결정] 표시)
- **Δ 부호**: 우리 Δ_i = w_i^local − W_t(논문과 반대 부호), Δ̄ 방향에 W_{t+1} = W_t + η_g · Δ̄_MSEAvg. 노름은 부호 무관. [결정, 사소]
- **D-w(가중)**: "MSEAvg 위에"가 목적이므로 평균은 기존 MSEAvg 가중 평균 W̄_t(역-검증MSE 가중, 가중치 q_i, Σq_i=1), Δ̄ := W̄_t − W_t. 분자는 가중 일반화 Σ_i q_i‖Δ_i‖² (q_i=1/M이면 논문 식과 같음), 분모 2(‖Δ̄‖²+ε). 논문은 균등 가중만 다룸 → 가중 일반화는 [결정]. 균등 가중 대안은 이번 시험 범위 밖(탐색 보류).
- **D-M(참여 수)**: 논문 규칙대로 그 라운드 참여 클라이언트에 대해서만 계산(N-BaIoT·CIC 5명, ToN 4명). 분자에서 M이 가중 합으로 흡수되므로 별도 M 항 없음. [결정: 위 가중 일반화에 포함]
- **D-ε(ε 값)**: ε=10^-3 하나로 고정. 근거(사전, 우리 데이터 보지 않음): 논문 격자의 최소값이자 CIFAR 3종 최적값이며, 논문이 규칙을 'FedAvg를 외삽으로 확장' 쪽(작은 ε)으로 쓰는 기본값. ε=0(합성 실험)은 후반 ‖Δ̄‖→0에서 폭주 위험이라 채택하지 않음. 이 선택은 논문의 단일 권장값이 아니라 [결정]이며 결과 후 변경 금지. (우리 로그에서 ‖Δ̄‖² 규모는 대략 0.1~0.5 수준이라 10^-3은 분모의 약 1% 이하 — 규모는 사전 점검 문서가 아닌 기존 로그의 global_disp 기반 대략치.)
- **D-τ(로컬 스텝 수)**: 식에 τ가 직접 들어가지 않음(Δ_i만 사용). FedMSE 로컬 학습은 조기 종료(patience 3, 최대 100 epoch)라 클라이언트별 스텝 수가 다르다. 논문은 균일 τ를 가정 → 이질적 τ_i는 [결정: 그대로 Δ_i를 사용]하며 이 가정 위반은 한계로 보고.
- **D-토폴로지**: parallel(모든 참가자가 같은 글로벌 모델에서 시작)로 논문 Alg.1과 일치. 기존 D0/D1 셀도 parallel.
- **D-대상 파라미터**: D1과 같이 state_dict 전체 float 항목에 동일 η_g 적용(층별 아님). [결정]
- **D-하한 1**: 논문대로 max{1,·}. 따라서 FedExP는 D0보다 걸음을 줄이지 않음(외삽만) — ToN 같은 진동 취약 설정에서 해로울 수 있음(사전 위험).
- **그 외 불변**: 클라이언트 lr 1e-5, batch 12, patience 3, 최대 100 epoch, 40라운드, 참여 5/10(ToN 4/8), 시드 run×10000, 참여 순서 D0와 동일.

## 3. 비교·셀·런 수
- 신규 variant `mse_fx`(구현은 승인 후; 실행기 변경은 가산적, 단위시험: ①q_i=균등·ε 동일 조건에서 독립 numpy 참조구현의 η_g와 일치 ②η_g=1이면 D0 경로와 비트 동일 ③합성 벡터에서 상한·하한 확인 ④첫 라운드 η_g 후 W가 규칙대로 갱신).
- **주 가설군(확증)**: data_seed 1234, run 10–19, N-BaIoT(repro-noniid-10clients.json)·ToN·CIC-km 각 10런 = **30런**. 기준선은 기존 D0 셀(D0_mse_par, D0_ton_s1234, D0_cic_km_s1234)과 같은 run·참여 순서 짝비교(사후 검증), D1(D1_msem_par, D1_ton_s1234, D1_cic_km_s1234)과도 보조 짝비교.
- **복제 가설군(별도 가족)**: N-BaIoT data_seed 2024·4321·7777(D0·D1 기존 셀 `D0/D1_s{seed}_lr1e-5`) 각 10런, ToN data_seed 2024(`D*_ton_s2024`) 10런 = **40런**. CIC data_seed 2024는 기존 D0·D1이 없어 이번 범위 밖(새 기준선이 필요하므로 별도 승인 시).
- 총 **70런**(주 30 + 복제 40), 새 기준선 실행 0.
- 비용(대략, 불확실): 앞선 8~9개 동시 실행에서 2라운드 시험이 약 130초였으므로 40라운드 한 런은 동시 실행 수에 따라 대략 40~45분(24코어, 20 동시 가정). 30런은 약 1.5~2시간, 70런은 3~4시간 추정(미확정, 실측 아님).

## 4. 판정(사전 고정)
- 주 지표: 런별 R31~R40 클라이언트 평균 AUC의 평균, 짝차 X−D0, 양측 95% t 구간(df=n−1). 셀 통과 = 하한 > +0.3%p.
- 다중 비교: 주 가설군 3셀에 Holm(α=0.05, H0: 차 ≤ +0.3 단측 t검정 p값에 적용), 복제 가설군 4셀에 별도 Holm. 가족을 합치지 않음. 데이터셋 판정: 그 데이터셋의 모든 셀(주+복제)이 통과해야 "통과", 일부면 "부분", 아니면 "불통과". 데이터셋별 따로 보고, 합치지 않음.
- 발산(R5 이후 평균 AUC<0.90)은 제외하지 않고 개수 보고. 미완 런은 해당 짝에서만 제외하고 n 표기.
- **탐색 지표(판정 아님)**: 라운드별 η_g(중앙값, 최대, η_g>1.5 비율), 라운드 간 AUC 2%p 이상 낙하 횟수, 이탈 라운드(D0보다 3%p 이상 낮아짐), ToN 호스트 .195/.190/.152의 클라이언트별 AUC 대 D0·D1, 서버 이동거리 대 D0, D1 대비 짝차, R20/R40 짝차, 0.97 유지 도달 라운드.
- 재현·무결성 점검: 로깅 항목(η_g, Σq_i‖Δ_i‖², ‖Δ̄‖², 평균·최대 참여 델타 노름)을 diag2에 기록. 첫 라운드 로컬 학습 결과가 D0와 동일해야 함(같은 시작·같은 시드): X의 라운드 1 클라이언트 델타 노름이 D0 로그의 local_disp와 일치하는지 확인(불일치 시 DEVIATIONS 기록).

## 5. 한계
ε는 논문의 단일 값이 아닌 선택(결정), 가중 일반화·조기종료로 인한 τ_i 이질성은 논문 가정 밖, 이론(식 (6))은 볼록 과대매개변수 설정, 시험은 FedExP 한 규칙·ε 한 값만 검정, CIC는 인위적 비IID(KMeans) 한계, ToN 호스트 8개, 결과 후 설정·기준 변경 금지(DEVIATIONS_fedexp.md에만 기록).
