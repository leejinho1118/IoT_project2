# lit_B 독립 문헌 판정

작업 폴더가 읽기 전용이어서 `.md` 파일을 저장할 수 없었습니다. 아래에 마크다운 문서 본문을 제공합니다. 지정된 증거 파일만 사용했고, 다른 판정자의 결과 파일은 열지 않았습니다. 시험은 실행하지 않았습니다.

**첫 시험은 D1의 방향 재시작을 권고합니다.** D1이 제안한 이동이 이번 MSEAvg 업데이트와 반대 방향일 때만 과거 모멘텀을 버립니다. ToN에서 관찰한 방향 누적 문제를 직접 겨냥하면서, 두 방향이 맞는 라운드에는 D1의 걸음을 그대로 씁니다. 이것은 원문의 재시작 판정식을 FedMSE에 옮긴 가설입니다. AUC 개선 여부는 짝비교로 판정해야 합니다.

## 근거와 공통 시험 규칙

**[관문통과]**는 수집 인용이 기계 관문을 통과했다는 뜻입니다. **[원문확인]**은 수식, 추가 근거 또는 실패 인용의 내용을 해당 `pdf/<id>.txt`에서 직접 확인했다는 뜻입니다. **[미검증]**은 원문에서 못 찾았거나 추출 텍스트의 표기가 충돌해 확정하기 어려운 경우입니다. 쪽수는 원문의 인쇄 쪽수를 따릅니다. \(d_{i,t}=W_{i,t}^{\text{local}}-W_t\), \(\Delta_t=\bar W_t-W_t\)로 씁니다. 원문 식은 각 논문의 부호를 따르고, FedMSE 시험안은 이 정의를 따릅니다.

아래의 모든 시험 초안에는 다음 규칙을 적용합니다.

- **짝 셀.** N-BaIoT·ToN·CIC에서 같은 후보 규칙과 상수를 쓴다. 각 데이터셋에서 후보를 기존 D0·D1·D2 각각과 같은 run ID, 초기화, 데이터 분할, 라운드 수, 참여 클라이언트 및 참여 순서로 짝짓는다. 집계만 바꾸는 후보는 기존 로컬 학습과 MSEAvg 가중치 계산을 사용한다.
- **판정.** 기존 오프라인 AUC 평가기의 데이터셋 집계 방식으로 고정 최종 라운드의 run별 AUC 차이(%p)를 계산한다. 세 데이터셋 × 세 기준선의 9개 대비를 한 묶음으로 Holm 보정한다. 모든 대비의 보정된 95% 구간 하한이 \(+0.3\)%p를 초과해야 통과한다. 후보를 동시에 여러 개 확증 시험에 넣는 경우에는 후보 간 다중비교 범위도 공개 전에 동결한다.
- **동결.** 원문에서 가져올 설정, 구현상 예외 처리, run 목록, 평가 시점과 통계 계산법을 후보 결과를 보기 전에 확정한다. 서버 갱신에 평가 라벨이나 AUC를 입력하지 않는다. 아래에서 도입 조건을 충족하지 못한 시험안은 기존 세 기준선을 사용한다는 설계만 남기고 보류한다.

## 1. FedExP — 2301.09604

- **① 원문 규칙.** [관문통과] §1은 라운드별 의사 그래디언트로 서버 걸음을 정한다고 설명한다. [원문확인] p. 5, 알고리즘 1, 9–12행에서 \(q_i=w_t-w_{i,\mathrm{local}}\), \(\bar q=M^{-1}\sum_iq_i\), \(\eta_t=\max\{1,\sum_i\|q_i\|^2/[2M(\|\bar q\|^2+\epsilon)]\}\), \(w_{t+1}=w_t-\eta_t\bar q\)를 확인했다. 실패한 갱신식과 \(\epsilon,\eta_l\) 격자 탐색 문장은 각각 알고리즘 1과 §6 p. 8에서 확인했다. 부록 D.3–D.4는 \(\epsilon\in\{10^{-3},10^{-2.5},10^{-2},10^{-1.5},10^{-1}\}\)를 제시하고 \(10^{-3}\)을 출발값으로 권한다. 표 3의 EMNIST 선택값은 \(10^{-1}\)이다.
- **② 신호.** [원문확인] 알고리즘 1 및 p. 5의 부분 참여 설명에 따르면 참여자의 업데이트 제곱노름 평균과 평균 벡터의 제곱노름을 쓴다. 서버 라벨·검증셋은 갱신에 필요 없다. 논문의 분류 실험은 학습 정확도로 격자값을 선택했다(부록 D.3).
- **③ 적용 가능성 — 가능.** MSEAvg 방향에 라운드별 배율을 곱할 수 있다. 원문의 균등 가중을 MSEAvg 가중으로 바꾸는 효과는 별도의 가설이다.
- **④ 신호 이용 — 예.** 참여별 벡터·노름, MSEAvg 가중치와 \(\Delta_t\)로 계산할 수 있다.
- **⑤ 시험 초안.** 공통 짝비교에서 \(W_{t+1}=W_t+\eta_t\Delta_t\), \(\eta_t=\max\{1,\sum_i a_{i,t}\|d_{i,t}\|^2/[2(\|\Delta_t\|^2+10^{-3})]\}\)를 사용한다. \(a_{i,t}\)는 합이 1인 기존 MSEAvg 가중치다. 걸음 규칙의 효과를 보기 위해 기존 평가 모델을 사용한다.
- **⑥ 위험·한계.** 배율 하한이 1이라 D0보다 걸음을 줄이는 라운드는 없다. 큰 개별 업데이트가 서로 상쇄될 때 과도한 확대가 생길 수 있다. 원문도 진동을 관찰했고, 실험에서는 마지막 두 모델의 평균을 사용했다(§5 마지막 단락, pp. 7–8). 위 시험은 그 평균을 도입하지 않는 걸음 규칙 시험이다.

## 2. LARS — 1708.03888

- **① 원문 규칙.** [원문확인] §4 p. 4, 식 (4)–(6)에서 실패 인용의 층별 표기는 \(\lambda^l\)이다. \(g^l=\nabla L(w^l)\), 층별 이동 크기를 정하는 식은 \(\gamma\lambda^lg^l\), \(\lambda^l=\eta\|w^l\|/\|g^l\|\)이다. 가중치 감쇠를 넣는 식 (6)은 분모를 \(\|g^l\|+\beta\|w^l\|\)로 바꾼다. 알고리즘 1은 \(v^l\leftarrow m v^l+\gamma_{t+1}\lambda^l(g^l+\beta w^l)\), \(w^l\leftarrow w^l-v^l\)를 제시한다. [관문통과] §5 각주 6의 실험값은 \(m=0.9,\ \beta=0.0005,\ \eta=0.001\), 다항 감쇠 지수 \(2\)다. [미검증] 알고리즘 1의 \(\lambda^l\) 줄에는 식 (6)의 \(\eta\)가 빠져 있다. 두 표기를 맞춰 주는 설명을 원문에서 못 찾았다.
- **② 신호.** [관문통과] §2는 훈련 미니배치의 손실 그래디언트를 사용한다. [원문확인] §4의 층별 비율은 파라미터와 그래디언트 노름에서 계산한다. 서버 라벨·검증셋은 비율 계산에 필요 없다.
- **③ 적용 가능성 — 조건부.** 층별 \(-\Delta_t^l\)를 의사 그래디언트로 사용하면 식 (5)의 서버 적용안을 만들 수 있다.
- **④ 신호 이용 — 부분.** 층별 모델 가중치와 업데이트를 코드에서 구할 수 있다. 원문의 미니배치 그래디언트는 현재 서버 신호로 주어지지 않는다.
- **⑤ 시험 초안.** 공통 짝비교에 식 (5)의 감쇠 없는 서버 적용안을 한 셀로 둔다. 예를 들면 표 3의 기초 LR \(2\)와 \(\eta=0.001\)을 고정해 \(\Delta_t^l\)에 \(2\eta\|W_t^l\|/\|\Delta_t^l\|\)를 곱한다. 표 3의 웜업을 옮기지 않은 단순식이며, 영벡터는 이동 0으로 정의한다.
- **⑥ 위험·한계.** 0이 아닌 층별 이동의 노름이 업데이트 노름과 무관해진다. 작지만 잡음이 큰 층도 움직일 수 있고, 초기 가중치가 0인 층은 멈출 수 있다. §6의 배치 크기 결과를 비IID 연합학습의 AUC 근거로 옮기기 어렵다.

## 3. 신뢰비율 클리핑·LAMBC — 2011.13584

- **① 원문 규칙.** [관문통과] §2.1은 신뢰비율을 층별 노름의 비로 설명한다. [원문확인] 식 (2)는 \(w_{t+1}^l=w_t^l-\eta_t[\phi(\|w_t^l\|)/\|g_t^l\|]g_t^l\)이다. 알고리즘 1의 LAMBC는 Adam식 방향 \(r_t=m_t/(\sqrt{v_t}+\epsilon)\)에 대해 \(c_t^l=\operatorname{clip}(\phi(\|w_t^l\|)/\|r_t^l\|)\), \(w_{t+1}^l=w_t^l-\eta_t c_t^l(r_t^l+\lambda w_t^l)\)를 쓴다. §3–§4.2에서 수치 하한 \(0\), CIFAR-10의 상한 \(1\) 및 비교 상한 \(1,3,5,10\)을 확인했다. [미검증] 식 (3)과 바로 뒤 문단은 \(\mu,\tau\)의 상·하한 역할을 서로 바꿔 적는다. 알고리즘 1의 모멘트 보정 줄도 분모를 \(1-\beta_j\)로 인쇄한다. 다른 지수로 고쳐 읽을 근거를 원문에서 못 찾았다.
- **② 신호.** [관문통과] 알고리즘 1은 훈련셋에서 미니배치를 뽑는다. [원문확인] 갱신에는 층별 가중치, 훈련 그래디언트에서 만든 모멘트와 그 노름을 쓴다. 클리핑 자체에 서버 라벨·검증셋은 필요 없다.
- **③ 적용 가능성 — 조건부.** 상한 1을 쓰는 층별 클리핑은 MSEAvg 방향에 적용할 수 있다. 이식 가능한 부분은 클리핑 규칙이다.
- **④ 신호 이용 — 부분.** 층별 \(W_t,\Delta_t\)는 얻을 수 있다. 원문의 그래디언트 기반 Adam 방향은 현재 로그에 없다.
- **⑤ 시험 초안.** 공통 짝비교에서 \(\Delta_t^l\)에 \(\operatorname{clip}(\|W_t^l\|/\|\Delta_t^l\|,0,1)\)을 곱하는 셀을 둔다. \(\Delta_t^l=0\)이면 층 이동을 0으로 정의한다. 배율 1은 기존 D0의 서버 스케일이다.
- **⑥ 위험·한계.** D0 대비 층별 걸음을 유지하거나 줄이는 방식이다. 작은 걸음이 필요한 경우에만 도움이 되며 층 사이의 상대적 이동이 달라진다. §4.2는 후반에 클리핑이 도움이 될 수 있다고 보고한다. 후반 시작점을 자동으로 정하는 수치 규칙은 원문에서 못 찾았다.

## 4. Adaptive Restart — 1204.3982

- **① 원문 규칙.** 관문 실패 3건을 모두 [원문확인]했다. §3.2 p. 6에서 함수 방식은 \(f(x^k)>f(x^{k-1})\), 그래디언트 방식은 \(\nabla f(y^{k-1})^\top(x^k-x^{k-1})>0\)이면 재시작한다. §1 p. 1은 현재 반복점을 새 시작점으로 두고 모멘텀을 0으로 되돌린다고 설명한다. §2 p. 2, 알고리즘 1 및 식 (2)는 매끄러운 볼록 문제에서 \(t_k\le1/L\), 예시 설정 \(t_k=1/L,\ q=0\)을 제시한다. 이는 기초 가속법 설정이다. 재시작 판정 경계는 \(0\)이다.
- **② 신호.** [원문확인] 함수 방식은 두 반복점의 목적함수 값, 그래디언트 방식은 \(y^{k-1}\)에서의 그래디언트와 실제 이동 벡터를 사용한다. §3.2는 가속법이 이 벡터들을 이미 계산한다고 설명한다. 판정식에 별도 라벨이나 검증셋은 입력되지 않는다. 함수 방식에 정상 검증 MSE를 넣으면 그 MSE가 대리 목적함수가 된다.
- **③ 적용 가능성 — 조건부.** FedMSE에서 원문의 그래디언트 대신 \(-\Delta_t\)를, 이동 대신 D1의 제안 이동을 쓰는 방향 검사를 시험할 수 있다.
- **④ 신호 이용 — 부분.** \(\Delta_t\), 직전 모멘텀, 제안 이동, 검증 MSE는 이용 가능하다. 원문의 외삽점 그래디언트는 없다. \(\cos(\Delta_t,v_{t-1})\)만 검사하면 원문의 이동 벡터에 대응하는 항이 달라진다.
- **⑤ 시험 초안.** 공통 짝비교에 아래 첫 시험의 D1 방향 재시작 셀을 추가한다. 함수 방식은 이번 시험에 넣지 않는다.
- **⑥ 위험·한계.** 상쇄되거나 잡음이 큰 \(\Delta_t\)가 방향 판단을 흐릴 수 있다. 이번 적용안은 이동 전에 판정하며, 원문은 생성된 반복점의 이동을 판정한다. 원문의 가속·수렴 결과는 FedMSE나 호스트 AUC에 그대로 적용할 수 없다. 검증 MSE 기반 방식도 우리 설정에서 관찰된 MSE–AUC 불일치의 영향을 받는다.

## 5. AdEMAMix — 2409.03137

- **① 원문 규칙.** [관문통과] §3 p. 5는 느린 EMA를 추가하고, 자주 사용한 \(\beta_3=0.9999\)와 실험 범위 \(\alpha\in[4,10]\)을 보고한다. [원문확인] §3 식 (AdEMAMix) 및 알고리즘 1에서 \(m_{1,t}=\beta_1m_{1,t-1}+(1-\beta_1)g_t\), \(m_{2,t}=\beta_3m_{2,t-1}+(1-\beta_3)g_t\), \(u_t=\beta_2u_{t-1}+(1-\beta_2)g_t^2\)이다. 세 상태는 0에서 시작한다. \(\hat m_{1,t}=m_{1,t}/(1-\beta_1^t)\), \(\hat u_t=u_t/(1-\beta_2^t)\)로 보정하고 \(\theta_t=\theta_{t-1}-\eta[(\hat m_{1,t}+\alpha m_{2,t})/(\sqrt{\hat u_t}+\epsilon)+\lambda\theta_{t-1}]\)로 갱신한다. 부록 A Listing 1의 기본값은 \((\beta_1,\beta_2,\beta_3)=(0.9,0.999,0.9999),\ \alpha=5,\ \eta=10^{-3},\ \epsilon=10^{-8},\ \lambda=0\), 두 웜업 길이 \(0\)이다.
- **② 신호.** [관문통과] §3은 배치 손실 그래디언트를 정의한다. [원문확인] 알고리즘 1은 그래디언트와 상태만으로 갱신한다. [관문통과] 부록 B의 ImageNet 검증 손실은 모델 선택에 사용했다.
- **③ 적용 가능성 — 조건부.** \(g_t=-\Delta_t\)로 대입하면 서버에 이식할 수 있다. 논문의 한 최적화 갱신과 연합학습 한 라운드는 시간 단위가 다르다.
- **④ 신호 이용 — 부분.** MSEAvg 벡터와 서버 모델로 대리 신호·모멘트를 계산할 수 있다. 원문의 배치 그래디언트는 없다.
- **⑤ 시험 초안.** 공통 짝비교에서 Listing 1 기본값 한 세트로 서버 AdEMAMix 셀을 정의한다. 초기화·웜업·마지막 평가 시점을 세 데이터셋에 동일하게 적용한다.
- **⑥ 위험·한계.** \(\beta_3=0.9999\)의 반감 길이는 원문 기준 약 6,930갱신이다. 수십 라운드 시험에서는 느린 버퍼의 장점을 판단하기 어렵다. 원문도 큰 \(\beta_3\)에서 초기 불안정을 보고했다(§3 pp. 5–6). 언어모델 손실 격차의 포화 관찰은 FL 이질성이나 SAE AUC의 근거로 쓰기 어렵다.

## 6. FedAvgM — 1909.06335

- **① 원문 규칙.** [관문통과] §4.2의 설명식은 \(v\leftarrow\beta v+\Delta w,\ w\leftarrow w-v\)다. 실험은 Nesterov를 사용했고 \(\beta\in\{0,0.7,0.9,0.97,0.99,0.997\}\)를 비교했다. [원문확인] §4.2는 서버 LR \(1.0\)과 \(\eta_{\mathrm{eff}}=\eta/(1-\beta)\)를 명시한다. 여기서 유효 LR에 쓰인 \(\eta\)는 논문의 클라이언트 LR이다. FedMSE 부호로 바꾼 설명식의 \(\beta=0.9\)는 D1이다. D2는 같은 \(\Delta_t\) 열과 0 초기화에서 버퍼 입력을 \(1-\beta=0.1\)로 정규화한 형태다.
- **② 신호.** [원문확인] §4.2 설명식은 표본 수 가중 모델 업데이트와 과거 버퍼를 사용한다. 서버 라벨·검증셋은 갱신에 필요 없다. [관문통과] §3의 클래스 라벨은 논문의 이질적 분류 실험 설정에 쓰였다.
- **③ 적용 가능성 — 가능.** MSEAvg 위에 설명식이 이미 D1으로 구현돼 있다.
- **④ 신호 이용 — 예.** \(\Delta_t\)와 서버 버퍼를 쓸 수 있다.
- **⑤ 시험 초안.** 공통 짝비교의 D0·D1·D2를 유지한다. 설명식에 새 셀을 추가하면 D1과 중복된다. 논문의 Nesterov를 별도 비교하려면 9번의 FedNAG처럼 구현식을 먼저 고정하고 독립 셀로 검정한다.
- **⑥ 위험·한계.** 원문에서 참여율이 낮을 때 유효 LR의 허용 범위가 좁고, 긴 로컬 학습에서 업데이트 분산이 증가했다고 보고한다(§4.2). 우리 데이터의 효과 방향은 서로 달랐다. 일정한 방향의 같은 \(\Delta_t\)를 계속 받는다고 가정하면 D1의 버퍼는 \(10\Delta_t\), D2는 \(\Delta_t\)에 접근한다. 실제 학습에서는 모델 경로가 달라져 입력도 달라진다.

## 7. Adaptive Federated Optimization — 2003.00295

- **① 원문 규칙.** [관문통과] §2는 \(-\Delta_t\)를 서버 의사 그래디언트로 쓰며 FedAvg의 서버 LR은 \(1\)이라고 설명한다. 실험에서 FedAdam·FedYogi의 \((\beta_1,\beta_2)=(0.9,0.99)\)를 고정했다. [원문확인] §3 p. 4, 알고리즘 2와 부록 B 알고리즘 5에서 \(m_t=\beta_1m_{t-1}+(1-\beta_1)\Delta_t\)이다. FedAdam은 \(s_t=\beta_2s_{t-1}+(1-\beta_2)\Delta_t^2\), FedYogi는 \(s_t=s_{t-1}-(1-\beta_2)\Delta_t^2\operatorname{sign}(s_{t-1}-\Delta_t^2)\)를 쓴다. \(W_{t+1}=W_t+\eta m_t/(\sqrt{s_t}+\tau)\)이며 제곱·나눗셈은 좌표별이다. 초기화 요구는 \(s_{-1}\ge\tau^2\)다. 부록 D.4 표 8–9의 EMNIST AE 설정은 두 방법 모두 서버 \(\eta=10^{-3/2},\ \tau=10^{-3}\), 논문의 클라이언트 \(\eta_l=10^1\)이다.
- **② 신호.** [원문확인] 알고리즘 2·5는 집계 벡터와 서버 상태만으로 갱신한다. [관문통과] §4에서 상수 선택에는 마지막 100라운드 평균 훈련 손실을 사용했다. 검증셋은 성능 측정에 사용했다(§4).
- **③ 적용 가능성 — 가능.** 예제 수 가중 집계 대신 MSEAvg 벡터를 입력할 수 있다. 논문은 부분 참여와 비균등 가중의 확장도 언급한다(§3).
- **④ 신호 이용 — 예.** 좌표별 \(\Delta_t\)와 서버에서 새로 보관할 두 상태면 충분하다.
- **⑤ 시험 초안.** 공통 짝비교에서 먼저 FedAdam 한 셀만 둔다. EMNIST AE의 서버 상수를 그대로 쓰고 \(m_{-1}=0,\ s_{-1}=\tau^2\)로 동결한다. 이 초기화에서 \(s_{-1}\)은 원문 허용 경계이고, \(m_{-1}=0\)은 시험의 명시적 구현 선택이다. 클라이언트 LR은 기존 짝 셀 값을 사용한다. FedYogi는 동일 설정의 별도 후속 셀이다.
- **⑥ 위험·한계.** §5는 EMNIST AE에서 FedAdam·FedYogi가 FedAvgM보다 초기에 빨리 수렴했다고 보고한다. 이 근거는 재구성 학습의 선례다. 우리 SAE에서 업데이트의 좌표별 스케일과 AUC 반응은 확인되지 않았다.

## 8. FedWMSAM — 2511.22080

- **① 원문 규칙.** 실패 인용 3건 모두 [원문확인]했다. §4.2.2 p. 6 식 (1)–(2)에서 \(\Delta_r^k=\Delta_r+\alpha_r c_k/(1-\alpha_r)\), \(v_{b+1,k}^r=\alpha_rg_{b,k}^r+(1-\alpha_r)\Delta_r^k\)다. 혼합식은 알고리즘 1의 16행이다. §4.2.3 식 (3)–(4)는 \(\hat\alpha_{r+1}=|P_r|^{-1}\sum_{k\in P_r}\cos(\Delta_r,\Delta_r^k)\), \(\alpha_{r+1}=(1-\lambda)\alpha_r+\lambda\operatorname{clip}(\hat\alpha_{r+1},0.1,0.9)\)다. 알고리즘 1과 §5.1 p. 7의 값은 \(\alpha_0=0.1,\rho=0.01,\eta_l=0.1,\eta_g=1\)이다. 주 실험은 100클라이언트, 참여율 10%, 배치 50, 로컬 5에폭, 500라운드였다. 부록 B.2는 \(\lambda=0.01\)을 선택했다.
- **② 신호.** [원문확인] 코사인은 글로벌 모멘텀과 **개인화 모멘텀** 사이에서 계산한다. 알고리즘 1은 교란된 로컬 모델에서 그래디언트를 계산하고, §4.2.4 식 (5)는 클라이언트별·전역 보정 벡터를 갱신한다. 서버 라벨·검증셋은 이 갱신식에 들어가지 않는다. 논문은 분류 라벨로 이질적 분할과 정확도 평가를 구성했다(§5).
- **③ 적용 가능성 — 불가.** 원문 전체를 기존 MSEAvg 위의 서버 전용 한 셀로 적용하려면 로컬 교란 학습과 보정 상태가 필요하다.
- **④ 신호 이용 — 부분.** 코사인 계산과 참여별 모델 업데이트는 이용 가능하다. 논문에 필요한 개인화 모멘텀, 보정 벡터와 교란점 그래디언트는 현재 신호에서 바로 얻을 수 없다.
- **⑤ 시험 초안.** 공통 짝비교는 보류한다. 원문 방식의 도입을 검토하려면 로컬 학습과 보정 통신을 포함하는 변경을 명세한 뒤, 같은 참여 순서로 세 데이터셋에서 전체 알고리즘 셀과 D0·D1·D2를 비교한다.
- **⑥ 위험·한계.** [관문통과] §5.3은 참여율 20% 이후 정확도가 포화되고, 낮은 참여율 또는 강한 이질성에서 이득이 컸다고 보고한다. 그 결과는 결합된 전체 방법에 대한 것이다. 부록 B.3은 \(\lambda\)의 데이터셋 민감도와 코사인 변동도 보고한다.

## 9. Server Momentum in FL·FedGM — 2312.12670

- **① 원문 규칙.** [관문통과] §3은 FedGM이 과거 집계를 사용하고 \(\{\eta,\beta,\nu\}\)를 갖는다고 명시한다. [원문확인] §3 식 (2)의 원문 부호로 \(d_{t+1}=(1-\beta)\Delta_t^{\rm paper}+\beta d_t,\ h_{t+1}=(1-\nu)\Delta_t^{\rm paper}+\nu d_{t+1},\ x_{t+1}=x_t-\eta h_{t+1}\)다. \(\nu=1\)은 정규화된 버퍼를 쓰는 FedAvgM 계열, \(\nu=\beta\)는 FedNAG다. 다단계 알고리즘 3은 사전에 \(T_s,\eta_s,\beta_s,\nu_s\)를 받고, 식 (3)의 조건은 \(\eta_s\beta_s\nu_s/(1-\beta_s)\)와 \(T_s\eta_s\)를 단계별로 일정하게 둔다. §6.2의 예시는 \(\eta_s=(2,1,0.5)\), 전환은 143·429라운드다. 부록 H.3의 단일 단계 비교는 \(\beta=\nu=0.95\), \(\eta\in\{1,2,5\}\)다.
- **② 신호.** [원문확인] 알고리즘 3은 현재 집계, 과거 버퍼와 사전 지정된 라운드 단계를 쓴다. 서버 라벨·검증셋은 필요 없다. [관문통과] §4.1에서 포화 뒤 걸음을 줄이는 직관을 설명한다. 포화를 관측해 전환하는 자동 트리거는 원문에서 못 찾았다.
- **③ 적용 가능성 — 가능.** 단일 단계 FedGM은 MSEAvg 위에 적용할 수 있다. 원문의 다단계 예시를 40라운드에 그대로 적용하면 첫 전환에 이르지 못한다.
- **④ 신호 이용 — 예.** \(\Delta_t\), 버퍼와 라운드 번호를 쓸 수 있다.
- **⑤ 시험 초안.** 공통 짝비교에서 부록 H.3의 \(\eta=1,\beta=\nu=0.95\) 단일 단계 FedNAG를 한 셀로 둔다. 버퍼는 0에서 시작하며 FedMSE 부호로 최종 이동을 더한다. 다단계 경계를 비례 축소하는 규칙은 도입하지 않는다.
- **⑥ 위험·한계.** 초기 \(\eta=1\)에서 첫 걸음은 \((1-0.95^2)\Delta_t=0.0975\Delta_t\)다. 우리 D2에서 본 초반 지연을 다시 겪을 수 있다. 원문의 다단계 이득은 CIFAR-10의 훨씬 긴 학습에서 관찰했다.

## 10. Adaptive FedECADO — 2510.04203

- **① 원문 규칙.** [관문통과] §2.1은 활성 클라이언트의 ODE와 민감도 역할을 설명하고, 부록 G는 전역 허용오차 \(\gamma>0\)를 입력으로 둔다. [원문확인] 식 (7)은 \(\dot x_i^{k+1}+p_i\nabla f_i(x_i^{k+1})+I^k_{L_i}=0\)이다. 식 (11)은 민감도 \(\widehat G_i^{\rm th}=(1/\Delta t)\mathbf I+p_i\bar H_i\)를 쓴다. 서버는 식 (27)–(28)의 후진 오일러 갱신을 풀고, 부록 F 알고리즘 2는 \(\max|\epsilon_{\rm BE}|\ge\gamma\)인 동안 \(\Delta t\leftarrow\gamma\Delta t/\max|\epsilon_{\rm BE}|\)로 줄인다. 클라이언트에도 전진 오일러 오차에 대한 대응 규칙이 있다(부록 E). 부록 I 표 3은 탐색 범위 \(0\)–\(10^6\)을 제시한다. [미검증] 세 데이터셋에 그대로 가져올 단일 권장 \(\gamma\)는 원문에서 못 찾았다.
- **② 신호.** [원문확인] 식 (7), (11), (29)–(31) 및 부록 G 알고리즘 3은 로컬 손실의 그래디언트, 곡률 또는 그 근사, 결합 상태와 클라이언트 시뮬레이션 구간을 사용한다. 서버 라벨·검증셋은 적분 갱신에 필요 없다. 논문의 성능 비교에는 분류 정확도를 사용했다(§4.1).
- **③ 적용 가능성 — 불가.** 서버에서 기존 MSEAvg 집계 위의 걸음만 교체하는 범위에서는 필요한 클라이언트·서버 상태를 구성할 수 없다.
- **④ 신호 이용 — 부분.** 로컬 최종 모델은 있다. 민감도, 결합 벡터, 시뮬레이션 구간과 적분 오차는 현재 신호에 없다.
- **⑤ 시험 초안.** 공통 짝비교는 보류한다. 전체 알고리즘 도입이 범위에 들어오고 원문 근거로 양의 \(\gamma\)를 하나 동결할 수 있을 때, 세 데이터셋에서 전체 방법 셀을 기존 기준선과 비교한다.
- **⑥ 위험·한계.** 로컬 적분과 서버 집계를 함께 바꾸므로 효과를 MSEAvg 위의 모멘텀 조절에 귀속하기 어렵다. 수치 적분 오차는 AUC나 정상 검증 MSE의 포화 측정값과 용도가 다르다.

## 11. FedDuA — 2505.11126

- **① 원문 규칙.** [원문확인] 실패한 FedAvg 문장은 §2 p. 3에서 \(w_{t+1}=w_t+\eta_g\bar\Delta_t\)로 확인했다. FedDuA 본체는 §3 식 (3)과 알고리즘 1 p. 6이다. FedDuAdagrad는 \(s_t=s_{t-1}+\bar\Delta_t^2,\ v_t=\bar\Delta_t,\ m_t=\sum_{i\in S_t}\|\Delta_i^t\|^2/(2|S_t|)\)를 사용한다. FedDuAdam은 \(s_t=\beta_2s_{t-1}+(1-\beta_2)\bar\Delta_t^2,\ v_t=\beta_1v_{t-1}+(1-\beta_1)\bar\Delta_t,\ m_t=\beta_1m_{t-1}/2+(1-\beta_1)\sum_{i\in S_t}\|\Delta_i^t\|^2/(2|S_t|)\)를 사용한다. 세 상태는 0에서 시작한다. 공통으로 \(G_t=\operatorname{diag}(\sqrt{s_t}+\epsilon)\), \(\eta_{g,t}=m_t/(\|v_t\|_{G_t^{-1}}^2+\epsilon_g)\), \(w_{t+1}=w_t+\eta_{g,t}G_t^{-1}v_t\)다. [관문통과] 알고리즘 입력에는 \(\epsilon,\epsilon_g\)가 포함된다. [원문확인] §5는 \(\epsilon=10^{-9}\)와 Adam 계열 \((\beta_1,\beta_2)=(0.9,0.99)\)를 사용했고, 민감도 실험에서 \(\epsilon_g=0\)도 보고했다. 부록 G.3 표 6에서 FedDuAdagrad의 CIFAR-10·CIFAR-100·FEMNIST 선택값은 \(\epsilon_g=10^{-1}\)이다.
- **② 신호.** [원문확인] 알고리즘 1은 참여자별 업데이트 제곱노름, 집계 벡터와 서버 상태를 쓴다. 갱신에는 서버 라벨·검증셋이 필요 없다. 부록 G.3의 상수 선택에는 검증 정확도가 쓰였다.
- **③ 적용 가능성 — 가능.** MSEAvg 집계와 기존 참여별 벡터로 서버 규칙을 구성할 수 있다.
- **④ 신호 이용 — 예.** 개별 노름, \(\Delta_t\), 서버에서 계산할 대각 상태로 충분하다.
- **⑤ 시험 초안.** 공통 짝비교에서 우선 FedDuAdagrad 한 셀을 둔다. \(\epsilon=10^{-9},\epsilon_g=10^{-1}\)을 고정하고, \(\bar\Delta_t\)는 \(\Delta_t\)로, \(m_t\)는 \(\tfrac12\sum_i a_{i,t}\|d_{i,t}\|^2\)로 바꾼다. 기존 최종 모델 평가를 유지해 서버 규칙만 시험한다.
- **⑥ 위험·한계.** 좌표별 스케일과 전체 걸음을 동시에 바꾼다. 원문도 적응 걸음의 진동 때문에 마지막 두 모델을 평균했다(§5). 논문의 모멘텀 유무 비교 결과도 데이터셋마다 달랐다. MSEAvg 가중을 사용한 식에 원문 수렴 결과를 그대로 적용하기 어렵다.

| 2 | **MSEAvg 위 FedAdam** | 서버 집계 벡터만으로 계산할 수 있고, 원문에 오토인코더 실험과 가져올 서버 상수 한 세트가 있다. AUC 이득과 실제 걸음 크기는 확인이 필요하다. |
| 3 | **MSEAvg 위 FedExP** | 클라이언트 간 업데이트 차이를 바로 반영하는 서버 걸음 규칙이다. 방향은 D0와 같아서 과거 방향 누적을 피한다. 약한 합의를 확대할 수 있어 첫 시험보다 우선순위가 낮다. |

FedAvgM은 D1의 문헌 근거로 남긴다. FedGM과 FedDuA도 적용 가능한 후보로 남긴다. 이번 우선순위에는 D1 중복 여부, 수십 라운드에서 실제로 작동하는지, 관찰된 문제를 한 셀로 얼마나 직접 검정할 수 있는지를 반영했다.

## 첫 사전등록 시험 1개

**시험 셀은 D1 방향 재시작 하나다.** \(v_0=0\)에서 시작한다. 매 라운드 기존 MSEAvg로 \(\Delta_t\)를 만든 뒤 다음 식을 적용한다.

\[
p_t=0.9v_{t-1}+\Delta_t,\qquad
v_t=
\begin{cases}
\Delta_t, & \langle\Delta_t,p_t\rangle<0,\\
p_t, & \langle\Delta_t,p_t\rangle\ge0,
\end{cases}
\qquad W_{t+1}=W_t+v_t.
\]

내적이 음수면 그 라운드는 D0 방향과 크기로 움직이고 다음 라운드에는 이 새 버퍼를 이어간다. 내적이 0이면 D1 제안을 사용한다. 내적을 직접 계산하므로 영벡터에서 코사인을 나눌 필요가 없다. \(0.9\)는 기존 D1과 일치시키고, \(0\)은 논문의 재시작 경계를 사용한다. **의사 그래디언트, 이동 전 판정, 재시작 라운드의 D0 이동은 이 시험의 설계 선택이다.**

- **셀·런 수.** 데이터셋당 4셀, 전체 **12셀**이다. 이 중 **새 셀 3개**, 기존 기준선 9개다. 사전등록 목표는 **데이터셋당 30개 공통 run ID**다. 기준선이 모두 같은 조건으로 확보돼 있다면 새 실행 **90개**, 전체 분석 **360개 셀×run 관측**이다. 30은 제안한 고정 표본 수다. 증거 파일로는 기존 공통 run 수와 검정력을 확인할 수 없다. 공통 ID가 30개 이상이면 ID 정렬 순서의 처음 30개를 사전 동결한다. 부족하면 이 표본 수의 시험은 등록 보류로 기록한다.
- **통계 초안.** 각 대비에서 같은 run의 최종 AUC 차이로 짝 \(t\) 통계량을 계산한다. 공통 가설 마진 \(c\)에 대한 단측 \(p\)값 9개에 Holm을 적용한다. 양측 95% 구간의 하단에 해당하는 꼬리 수준 \(0.025\)에서 각 대비가 기각되는 공통 마진의 상한을 보정 하한으로 산출한다. **9개 하한이 모두 \(+0.3\)%p보다 커야 통과**한다. 이 계산법과 기존 AUC 집계 방식은 실행 전에 동결할 항목이다.
- **해석용 기록.** 재시작 라운드, \(\langle\Delta_t,p_t\rangle\), 제안·실제 이동 노름을 남긴다. ToN 약한 호스트의 AUC 궤적은 오프라인 진단에만 쓴다. 런 수나 발동 규칙을 진단 결과로 변경하지 않는다.

## 모르는 것/미검증 목록

- **[미검증]** 지정 증거에는 기존 D0·D1·D2의 공통 run ID 수, run별 짝차이 분산, 정확한 기존 AUC 집계 정의가 없다. 따라서 30런의 확보 여부와 검정력은 미확인이다.
- **[미검증]** FedMSE의 \(-\Delta_t\)가 adaptive restart 원문의 외삽점 그래디언트를 얼마나 잘 대신하는지, 방향 재시작이 ToN 호스트의 낙하를 줄일지는 모른다.
- **[미검증]** LARS 알고리즘 1과 식 (6)의 \(\eta\) 표기 차이, LAMBC의 \(\mu,\tau\) 역할과 모멘트 보정 표기를 해소하는 설명은 원문에서 못 찾았다.
- **[미검증]** FedGM에서 포화를 직접 판정하는 자동 전환 규칙, Adaptive FedECADO에서 가져올 단일 권장 \(\gamma\), FedWMSAM에서 보정 상태를 생략해도 같은 효과가 난다는 근거는 원문에서 못 찾았다.
- **[미검증]** 원문의 균등·예제 수 가중을 역검증 MSE 가중으로 옮긴 FedExP·FedOpt·FedDuA가 N-BaIoT·ToN·CIC 모두에서 \(+0.3\)%p 기준을 넘는지는 확인되지 않았다.
