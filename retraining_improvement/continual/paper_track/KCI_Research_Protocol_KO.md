# 한국전기전자학회 투고를 위한 연구 전환안
작성: 20222038 이진호
현재 판정: 예비 탐색 완료, 투고용 확증 결과 미확보. 이 문서는 학회 게재 가능성을 보증하지 않습니다.

## 목표와 잠정 제목
검증 예산과 정상 승인 오류를 고려한 연합 IoT 침입 탐지의 안전한 지속 갱신
Budget-Constrained Safe Continual Updates for Federated IoT Intrusion Detection under Verification Errors

핵심 질문: 승인된 신규 정상에 공격이 섞일 수 있고 확인 가능한 정상 라벨 수가 제한될 때, 기억 승격·갱신 보류·롤백 정책이 같은 메모리/확인 예산에서 적응과 기존 성능을 유지하며 오염 피해를 줄이는가?
아직 신규성이 확인된 알고리즘이 아니라 연구 가설입니다. 선행연구의 위협모델·예산·선별 규칙을 원문과 코드로 대조한 후 최종 기여를 확정해야 합니다.

## 현재 결과의 투고 장애
1. 같은 보류 풀을 반복 열어 봤으므로 현재 숫자는 탐색 결과다. 새 모델 선택에 다시 쓰지 않는다.
2. PCA A/B는 모의 특징 변화이며 실제 시간/물리 기기 드리프트가 아니다.
3. 입력 전용 kNN도 SAE보다 좋아 신경망/연합학습의 필요성이 미확인이다.
4. 원본 코드와 논문 식/절차 차이가 있어 코드 재현과 논문 재현을 구분해야 한다.
5. 입력 전용 결과의 시드 복제는 독립 반복이 아니다.
6. 라벨 정답을 검증자로 쓰는 이상적인 조건을 운영 가능성으로 확대 해석하면 안 된다.
7. 메모리 참조 공격 혼입 약4.79%에서 탐지율이 크게 붕괴했다. 방어 해결은 아직 아님.
8. AUC/TPR만 높다고 충분하지 않다. 정상 보정 표본량·오탐·경보 정밀도·자원비용이 필요하다.

## 제안할 방법의 최소 구성
- 별도의 신뢰 정상 앵커와 확인 대기 큐. 이상 점수만으로 정상을 승인하지 않는다.
- 확인 예산 안에서 대표성/불확실성을 고려한 확인 요청. 요청 수, 확인 지연, 오승인을 명시한다.
- 최근 승인 정상은 바로 장기 기억으로 승격하지 않고 분리한 후보 버퍼에 보관한다.
- 과거/현재 정상 기억 용량을 고정하고 중복·밀집 후보의 과도한 점유를 제한한다.
- 갱신 전후 별도 보호용 정상 자료에서 오탐 악화·갱신량을 확인하고 배포 보류/롤백한다.
- 보호 앵커/보정 자료에 공격 정답을 몰래 사용하지 않는다. 앵커 오염도 별도 실패 조건으로 시험한다.
- MSEAvg와 모델 구조를 먼저 고정한다. 탐지 헤드만 갱신한 실험과 SAE 재훈련 실험을 구분한다.
이 구성 요소를 결합했다는 사실만으로 독창성을 주장하지 않는다. 새 승격/예산 규칙의 수식, 의사코드, 계산량과 필요한 가정을 정의해야 한다.

## 자료와 확증 설계
- 기존 prepared IID50/PCA A/B 및 모든 후속 결과: 개발/가설 생성 전용. 원본 결과는 그대로 유지.
- N-BaIoT 원자료: 실제 기기/공격 유형 경로를 보존. 9기기를50개의 실제 기기라고 표현하지 않음. 원자료라고 자동 독립 테스트가 되는 것은 아니므로 기존 사용 특징 해시와 중복도 감사.
- 독립 자료 후보: TON_IoT 네트워크 자료(시간/엔드포인트 메타데이터 점검) 우선 검토, CICIoT2023 대안. 같은 가중치를 서로 다른 특징 스키마에 그대로 적용하지 않고 자료별 초기 모델을 새로 학습.
- 개발 기기/캡처와 확증 기기/캡처를 먼저 분리. 같은 캡처의 인접 행이 학습/평가에 섞이지 않도록 블록 경계와 필요 간격을 정의.
- 시간 열이 확인된 자료만 시간 순서 실험을 주장. 기기별 유입 실험은 기기 변화 시나리오로 구분.
- 입력 scaler/특징 선택/드리프트 파라미터/임계값은 학습·개발에서만 결정. 최종 확증 라벨은 성능 산출 외 접근하지 않음.
- 정상 확인 후보와 미래 평가 자료를 별도 관리. 후보 공격은 정상 학습에서 제외하되 검증 오류 실험에서만 지정 비율로 오승인.
- 학습 난수와 기기/캡처/시간 시나리오 변동을 구분. 추론의 반복 계산을 독립 시드로 세지 않음.
- 최종 설정과 분할 해시를 동결한 뒤 확증 평가. 결과가 나쁘면 숨기거나 테스트에 맞춰 다시 튜닝하지 않고 다음 버전으로 분리.

## 사전 정의할 비교군
1. 원본 코드 기준 FedMSE / 같은 코드 수정 없이 재현한 기준.
2. 같은 초기 모델의 무갱신, 신규 정상만 재학습, 균일 리플레이.
3. 저비용 단순 기준: 입력 Euclidean/Chebyshev kNN, SAE-CEN, SAE 잠재 kNN.
4. 제안 정책: 동일 확인 예산/메모리/학습 상한에서 비교.
5. 제거 실험: 후보 격리 없음, 승격 규칙 없음, 보호 검사/롤백 없음, 과거 기억 없음.
6. 최근 선행 방법: SSF 등은 원문·코드 점검 후 동등한 라벨 가정을 맞출 수 있을 때 비교. 지도학습 방법을 정상 전용 환경에 그대로 비교하고 우월성을 주장하지 않음.

## 비용과 오염 실험
초기 검토 격자: 확인 예산1/5/10%, 정상 승인 오류0/1/5/10%, 총 기억64/128/256.
격자 최종 확정은 개발 단계 계산 비용/자료량 확인 후 수행하며 확증 결과로 조정하지 않는다.
초기 정상 앵커가 깨끗한 경우와 앵커도 오염된 경우를 분리. 후보 기억 오염과 연합 모델 업데이트 오염은 다른 위협 모델이며 후자는 검증 전 주장하지 않음.
실제 확인 요청 수·거절/대기 수·승격 수·공격 혼입 수와 비율 분모를 함께 기록.

## 주평가와 보고
주 지표는 사전에 고정한 정상 보정 절차에서의 공격 탐지율과 실제 FPR. FPR1%는 잠정 운영 목표이며 보장 아님.
보조: PR-AUC/ROC-AUC, 실제 공격 기저율별 precision, 기존 환경 성능 변화/망각, 신규 적응 지연, 기기별 최악 성능, 확인 요청 비용, 추가 학습 시간/스텝, 통신 바이트, 추론 p50/p95, 총 RSS와 기억 페이로드를 각각 보고.
동일 기기/캡처/시나리오의 paired 차이와 구간 추정. 행을 독립 표본으로 놓는 과도한 유의성 계산을 피함. 독립 단위가 부족하면 그 한계를 공개.
데이터셋2개나 시드5회 등은 이 연구의 권고 설계이지 학회의 공식 정량 요건이 아님.

## 다음 단계와 통과 기준
G0: 선행연구 원문/코드 비교와 기여 가설 확정. 단순 구성 변경과 중복이면 주제를 수정.
G1: 원자료 메타데이터/라이선스/용량 확인, 분할·중복 감사 및 특징 스키마 확정.
G2: 안전 승격 정책과 라벨 예산 시뮬레이터 구현, 개발 자료에서만 제거/비용 검증.
G3: 단순 입력 기준을 포함한 공정 비교에서 장점 또는 명확한 비용 절충 확인. SAE 기여가 없으면 별도 결론으로 반영.
G4: 설정 동결 후 독립 자료/미사용 기기·캡처 확증. 오염 강건성과 적응의 주장이 유지되지 않으면 투고 준비 완료로 표시하지 않음.
G5: 그림/표/수식/재현 코드 및 한계 작성, 지도교수/공동저자의 기여·저자 순서 검토 후 저자 합의로 투고.
현재 G0 진행. G1~G4는 미완료. 원자료 다운로드와 새 장시간 학습은 이 문서 작성 중 시작하지 않았음.

## 공식 투고 규정 확인 (2026-11-14 웹 열람)
독창적 미발표 연구, 제1 또는 교신저자 학회원, 일반 원고 A4 12매 기준 및 국내 투고 hwp, 최초/수정 심사용 원고 저자 식별정보 삭제, 국문 제목/저자/초록/그림·표 제목 영문 병기, 그림·표 내부와 참고문헌은 영문 등은 현행 공개 페이지 내용에 따름.
내부 보고서는 20222038 이진호 유지. 심사용 익명 원고에는 학번/이름을 넣지 않음. 투고 직전에 규정/양식 재확인 필요. 제출/회원가입/결제는 하지 않았음.
