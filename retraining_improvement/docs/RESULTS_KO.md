# 재학습 개선: 실제 결과와 한계
20222038 이진호 · 2026-11-16

## 1. 출발점과 비교 원칙

원본 GitHub 코드의 6조합×5회=30개 실행을 먼저 완료했다. 결과 구조·라운드·50클라이언트 AUC·25참여 조건과 소스 불변을 검증했다. 근거는 [원본 요약](../evidence/continual/original_baseline_summary.json)에 있다. 과거 수정 구현 full_output은 원본 결과에 합산하지 않았다.

공통 초기 전역 가중치는 별도 초기 학습으로 확보했다. 원본 로컬 model.cpt를 전역 모델로 쓰지 않았다. 비교군의 초기 모델·참여 순서·최대 표본·학습 예산을 맞추고, 검증된 정상만 학습했다. 실제 스텝 수는 조기 종료에 따라 달라진다. 초기 비용은 시드별 한 번 계산하고 scaler·CEN·임계값·버전도 저장했다.

## 2. V1: 세 방식 구현과 기본 비교

재학습 없음 / 신규 정상만 / 신규 정상+기존 정상 리플레이를 50클라이언트·5시드·3단계, 총 45개 기록으로 비교했다. 데이터 누수, 무갱신 가중치·지표 불변, 공통 참여·예산, 정상 라우팅을 검사하고 4,500개 클라이언트 AUC를 재계산했다. [독립 검증과 최종 단계 요약](../evidence/continual/output/full_v1/validation.json).

이 모의 유입 조건에서는 기존 성능 저하와 리플레이 우월성이 뚜렷하지 않아, 변화가 있는 모의 특징 분포를 별도로 구성한 V2로 확장했다. 분할이 달라 원본/V1/V2 수치를 직접 빼서 개선량으로 주장하지 않는다.

## 3. V2: A→B 모의 특징 분포와 리플레이

개발 정상 자료의 signed-log/PCA 축으로 A/B를 구성했다. 초기 A로 학습하고 B가 유입되는 조건이며 7방식×3단계×5시드=105개 평가다. 모든 V2 방식에 초기 A 표준화 뒤 고정 [-20,20] 포화를 적용했다. 이는 원본 재현과 구분하는 공통 수치 안정화 변경이다.

| 방식, 보류 0% | 기존 AUC | 신규 AUC | 신규 FPR | 신규 TPR |
|---|---:|---:|---:|---:|
| 무갱신 | 0.94699 | 0.41313 | 83.11% | 75.73% |
| 신규 정상만 | 0.87544 | 0.62978 | 44.68% | 81.05% |
| 기존 정상 128개 리플레이 | 0.92204 | 0.61606 | 57.31% | 88.62% |

리플레이는 신규 정상만 방식보다 기존 AUC 하락을 줄였으나 신규 AUC와 오탐률은 불리했다. 정상 CEN 기준도 다시 적합하므로 순수 신경망 가중치 망각 효과만 분리한 결과는 아니다. [7방식·시간·스텝·메모리](../evidence/continual/drift_v2/output/full_v1/FINAL_RESULTS_KO.md), [수치 CSV](../evidence/continual/drift_v2/output/full_v1/summary.csv).

## 4. A~E: 분석을 반영한 실제 재학습

| 안 | 변경 방향 |
|---|---|
| A | 무작위 보관 128개, 고정 25% 리플레이 기준 |
| B | 50% 리플레이로 기존 성능 유지 강화 |
| C | 정상 다양성을 고려한 farthest-first 보관 |
| D | 이전 개발 정상 복원 오차에 따라 비율 적응 |
| E | 개발 점수·기존 AUC 조건을 통과한 새 버전만 채택, 실패 시 이전 버전 유지 |

5시드·50클라이언트·3단계로 수행했다. 방향 선택은 개발 자료로 하고 E까지 선택을 고정한 뒤 해당 캠페인의 최종 평가를 개방했다. 아래는 마지막 단계 시드 평균이다. initial은 공통 초기 모델이다.

| 안 | 기존 AUC | 신규 AUC | 신규 FPR | 신규 TPR |
|---|---:|---:|---:|---:|
| initial | 0.94699 | 0.41313 | 83.73% | 77.91% |
| A | 0.91868 | 0.60752 | 58.26% | 88.12% |
| B | 0.95113 | 0.56392 | 62.25% | 91.20% |
| C | 0.90904 | 0.58523 | 58.10% | 89.46% |
| D | 0.92319 | 0.53572 | 63.56% | 88.73% |
| E | 0.93885 | 0.59331 | 61.45% | 83.24% |

A는 지정한 **개발 복합 점수**에서 선택됐다. 모든 지표의 최적안은 아니다. B는 기존 AUC에서 유리했다. 최종 신규 오탐률은 여전히 약 58~64%로 운영 적용에는 부족하다. 최종 결과를 보고 선택 안을 다시 바꾸지 않았다.

## 5. 재학습 이후 탐지 헤드 재검토

높은 오탐의 원인을 확인하기 위해 보존한 A 인코더를 동결하고 탐지 헤드와 정상 참조를 비교했다. 아래는 후속 탐색의 마지막 단계 신규 영역 수치다. 신경망 재학습 성과와 합치지 않는다.

| 탐지 구성 | 신규 AUC | 신규 FPR | 신규 TPR |
|---|---:|---:|---:|
| 같은 A 가중치 + 원래 CEN | 0.60752 | 58.28% | 88.12% |
| 입력+SAE 정상 기억, 현재 단계 | 0.98061 | 6.94% | 89.69% |
| 누적 우선순위 정상 기억, 사후 탐색 | 0.98386 | 7.67% | 93.73% |
| 입력 전용 Chebyshev kNN | 0.98485 | 6.60% | 92.49% |

입력 전용 기준선이 강하므로 **SAE가 추가로 기여했다는 근거는 부족하다**. 입력 전용 구성에서 분할·참조가 같아 반복 시드 결과가 동일한 것은 독립 5회 성공이 아니다. 누적 기억과 새 거리의 결합은 아직 실행하지 않았다.

검증자가 공격 약 4.79%를 정상으로 잘못 승인했을 때, 현재 단계 입력+SAE 후보는 개발 탐지율 약 89.30%→19.32%, Chebyshev는 92.15%→17.75%로 크게 악화됐다. 신뢰 정상 앵커 가드는 일부 회복했지만 해결한 것은 아니다. 저오탐 운용점 비교에서도 목표 FPR 1%를 충족한 구성은 없었다.

## 6. 남은 연구 제약

- 실제 시간·기기 매핑이 없는 모의 특징 분포 변화다. 미지 공격 유형이나 실제 시간 드리프트 일반화를 주장하지 않는다.
- 후속 실험이 이미 본 보류 풀을 재사용했다. 새 외부·기기별·시간별 확증 자료가 필요하다.
- A~E 공통 초기 모델의 과거 조기 종료에는 분리 전 검증 풀이 쓰였다. 완전히 새 확인 실험이라고 할 수 없다.
- CEN 기준과 임계값 재적합이 함께 변했다. 표현 재학습·정상 참조·임계값 효과를 분리한 통제 실험이 필요하다.
- 원시 정상 보관은 추가 개인정보 비용을 낳는다. DP/안전 집계는 구현하지 않았다. 특징 페이로드와 RSS·GPU 피크 메모리는 다르다.
- 논문 제곱 L2와 공개 코드 norm 손실 차이는 확인했으나 교정 재훈련은 미완료다.

현재는 구현과 탐색 근거가 갖춰진 단계다. KCI 투고 수준의 확증 연구 완료 상태는 아니다. [다음 연구 프로토콜](../continual/paper_track/KCI_Research_Protocol_KO.md)에 미완료 과제를 분리했다.
